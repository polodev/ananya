# Language Corner (ভাষার ঘর) — agent guide

Language-learning site taught in **Bangla**, mobile first. English (A2, B1, B2), Japanese (A1), German (A1).
Repo `polodev/language` → GitHub Pages `https://polodev.github.io/language/`. Sister project of `~/sites/sanjoy` (same engine idea).

## Structure
Home → language → course (level) → chapters **অধ্যায় 1 … N**; each chapter is one swipeable slide deck.
The learner already knows the English alphabet and numbers, so English starts at A2 with topic chapters only.
Japanese and German start with **letter/number chapters** (Japanese 1–7: hiragana, katakana, numbers; German 1–3: alphabet,
sound rules, numbers), then A1 topic chapters.

## Files
- `curriculum.py` — every course and chapter: Bangla title, topic, grammar focus, `kind` (`letters` or `topic`). Source of truth.
- `content/<lang>-<level>/ch-NN.json` — topic chapters (reading 8–9 lines, 10 words, 12 phrases, grammar with 3 quiz items, tip).
  Generated by muse (`tools/gen_content.py`), then **reviewed and fixed by hand** (`tools/patch.py`). Treat the JSON as source.
- `letters_ja.py` — kana tables, example words, numbers, and `romaji()` / `bangla()` converters. Japanese text is **kana only,
  words separated by spaces**; romaji and Bangla pronunciation are always computed, never typed.
- `letters_de.py` — German alphabet, sound rules, numbers (hand-written). German Bangla pronunciation in topic chapters follows
  these rules (`tools/de_pron.py` rewrites them with muse): d=ড t=ট w=ভ v=ফ z=ৎস, -er=আ, -ig=ইশ, ch=খ/শ, sp/st=শ্প/শ্ট.
- `site_topic.py` (topic decks), `site_letters.py` (letter/number decks), `engine.py` (HTML), `build.py` (everything).
- `validate.py` — checks counts, scripts (kana-only Japanese, no stray Chinese/Korean), formal Bangla, culture rules.
- `assets/app.css`, `assets/app.js` — the only CSS/JS. localStorage keys start with `lang:`.

## Content rules
- Bangla explanations address the learner as **তুমি** (validator flags আপনি/করুন… in teacher text).
- Culture: no alcohol, pork or beef; no religious rituals (prayer, salam, mosque, temple); festivals (Eid, Puja, Boishakh) are fine.
- Names: Rafi, Mitu, Tanvir, Nadia; Japanese: たなか, やまだ (hiragana), Bangladeshis in katakana (ラフィ, ミトゥ); German: Anna, Lukas, Frau Weber.
- Bangladeshi places: Dhaka ダッカ, Chittagong チッタゴン, Sylhet, Chandpur.

## Commands
```bash
python3 validate.py                       # must print "ok"
python3 build.py                          # regenerates every page
python3 tools/gen_content.py english/b1 --only 3 --force   # regenerate one chapter with muse (then review!)
python3 tools/dump.py english-b1 3        # compact view for review
python3 tools/patch.py english-b1 < fixes.txt              # apply "3 words.4.text = ..." style fixes
```
Check on an emulated phone (390×844, isMobile, hasTouch): no horizontal overflow, swipe works, quiz works, no console errors.
