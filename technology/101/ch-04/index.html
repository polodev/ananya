ওয়েবের ভেতরটা: ব্রাউজার থেকে সার্ভার

Inside the web: browser to server

ওয়েব আর ইন্টারনেট এক জিনিস নয় — ওয়েব ইন্টারনেটের ওপর চলে। আজ পেজের ভেতরটা দেখবে।

BrowserURLHTTPHTMLCSS

👉 ডান থেকে বামে swipe করো — প্রতিটি স্লাইডে একটা করে বড় ধারণা

মূল ধারণা
🕸️

ইন্টারনেট = রাস্তা, ওয়েব = রাস্তার ওপরের দোকান

ইন্টারনেট হলো নেটওয়ার্ক। ওয়েব হলো তার ওপর চলা একটা সার্ভিস — ব্রাউজারে দেখা পেজ, লিংক, ছবি।

একটা পেজ খোলার যাত্রা

1
URL

তুমি ঠিকানা লেখো বা লিংকে চাপো।

2
DNS

ডোমেইন নামের IP বের হয়।

3
Request

ব্রাউজার সার্ভারকে HTTP request পাঠায়।

4
Response

সার্ভার HTML, CSS, JS ফেরত দেয়।

5
Render

ব্রাউজার সাজিয়ে স্ক্রিনে দেখায়।

ওয়েবের চারটা ইট

browser, URL, HTTP, HTML

Browserপেজ দেখানোর অ্যাপChrome, Safari, Firefox।
URLপেজের ঠিকানাhttps://example.com/page।
HTTPব্রাউজার-সার্ভারের ভাষাrequest আর response।
HTMLপেজের কাঠামোহেডিং, প্যারাগ্রাফ, ছবি, লিংক।

ফ্রন্টএন্ড বনাম ব্যাকএন্ড

ফ্রন্টএন্ড

  • তুমি যা দেখো
  • HTML, CSS, JavaScript
  • ব্রাউজারে চলে

ব্যাকএন্ড

  • পর্দার পেছনের কাজ
  • Python, PHP, Node.js
  • সার্ভারে চলে

দোকানের শো-রুম বনাম রান্নাঘর আর লেজার।

বাকি তিনটা

CSS, JavaScript, server, database

CSSসাজসজ্জারঙ, ফন্ট, spacing।
JavaScriptনড়াচড়া আর লজিকক্লিক, ফর্ম, animation।
Serverঅনুরোধের উত্তরদাতাসার্ভারে চলা প্রোগ্রাম।
Databaseতথ্যের লেজারইউজার, অর্ডার, পোস্ট।

বাড়ি বানানো

চেনা জিনিসবাড়ি
→
টেকের নামওয়েবসাইট

HTML = দেয়াল আর ঘর। CSS = রঙ আর সাজ। JavaScript = লাইট, দরজা, সুইচ। Database = বাড়ির ফাইল আলমারি।

লগইন কীভাবে কাজ করে

1
ফর্ম

তুমি ইমেইল-পাসওয়ার্ড লেখো।

2
HTTPS

তথ্য এনক্রিপ্ট হয়ে সার্ভারে যায়।

3
Database

সার্ভার পাসওয়ার্ডের হ্যাশ মিলিয়ে দেখে।

4
Session

সার্ভার একটা cookie দেয়।

5
Dashboard

পরের পেজে তুমি লগইন থাকো।

API, JSON, cookie, session

অ্যাপের ভেতরের যোগাযোগ

APIদুই সফটওয়্যারের কথা বলার দরজাঅ্যাপ সার্ভারকে ডেটা চায়।
JSONডেটার সহজ ফরম্যাটনাম-মানের তালিকা।
Cookieব্রাউজারে রাখা ছোট টোকেনলগইন মনে রাখে।
Sessionসার্ভারের মনে রাখা অবস্থাতুমি কে, কী করতে পারো।

টেকের নামAPI

তুমি রান্নাঘরে ঢুকো না। ওয়েটার (API) তোমার অর্ডার নিয়ে যায়, রান্নাঘর (সার্ভার) খাবার বানায়, ওয়েটার ফিরিয়ে আনে।

স্ট্যাটিক বনাম ডায়নামিক সাইট

স্ট্যাটিক

  • একই HTML সবাইকে
  • খুব দ্রুত, সস্তা
  • ব্লগ, পোর্টফোলিও

ডায়নামিক

  • ব্যবহারকারী অনুযায়ী বদলায়
  • সার্ভার + ডেটাবেস
  • ফেসবুক, দোকান, ব্যাংক

আজকের বেশিরভাগ সাইট দুটোর মিশ্রণ।

রিকোয়েস্ট

একটা আধুনিক ওয়েবপেজ খুললে ছবি, CSS, JS, ফন্ট, অ্যাড — শতাধিক ফাইল আসতে পারে। তাই দ্রুত সাইট বানানো একটা দক্ষতা।

ছবি ছোট করলে সাইট দ্রুত হয়।

HTTPS = চিঠির খামে তালা

তালা মানে তথ্য এনক্রিপ্টেড। কিন্তু তালা দেখে সিদ্ধান্ত নিও না — ঠিকানা, সাইটের নাম, আর তুমি কী ইনপুট দিচ্ছ তা দেখো।

মনে রাখো

✓
ওয়েব = ইন্টারনেটের ওপরের সার্ভিস।
✓
HTML কাঠামো, CSS সাজ, JS লজিক।
✓
ফ্রন্টএন্ড ব্রাউজারে, ব্যাকএন্ড সার্ভারে।
✓
API দুই সফটওয়্যারের মধ্যে ওয়েটার।
