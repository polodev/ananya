সফটওয়্যার: অ্যাপ থেকে অপারেটিং সিস্টেম

Software: apps and the operating system

ফোনের প্রতিটা অ্যাপের পেছনে একটা অদৃশ্য ম্যানেজার থাকে। আজ তার নাম জানবে।

মূল ধারণা
🧩

হার্ডওয়্যার শরীর, সফটওয়্যার মন

চিপ আর স্ক্রিন দিয়ে তুমি কিছু করতে পারো না, যতক্ষণ না সফটওয়্যার বলে দেয় কী করতে হবে। সফটওয়্যার = নির্দেশনার সেট।

অ্যাপ খোলার সময়

1
ট্যাপ

তুমি আইকনে চাপ দিলে OS খবর পায়।

2
OS

অ্যাপের ফাইল খুঁজে মেমোরিতে লোড করে।

3
CPU

অ্যাপের নির্দেশনা এক এক করে চালায়।

4
স্ক্রিন

ফলাফল দেখায়, তোমার টাচের অপেক্ষা করে।

চারটা আলাদা জিনিস

OS, অ্যাপ, ড্রাইভার, ফার্মওয়্যার

OSসব অ্যাপের ম্যানেজারWindows, macOS, Linux, Android, iOS।
Appএকটা নির্দিষ্ট কাজক্যামেরা, ব্রাউজার, গেম।
Driverহার্ডওয়্যারের অনুবাদকপ্রিন্টার বা গ্রাফিক্স কার্ডকে OS-এর সাথে কথা বলায়।
Firmwareহার্ডওয়্যারের ভেতরের ছোট সফটওয়্যাররিমোট, রাউটার, ফোনের বুট অংশ।

অফিসের উদাহরণ

চেনা জিনিসঅফিস ম্যানেজার
→
টেকের নামঅপারেটিং সিস্টেম

ম্যানেজার ঠিক করে কে কোন ফাইল পাবে, কে কতটুকু সময় পাবে, কে আগে চলবে। OS ছাড়া অ্যাপগুলো একে অপরের কাজ নষ্ট করবে।

ডেস্কটপ বনাম মোবাইল

ডেস্কটপ

  • Windows, macOS, Linux
  • কিবোর্ড-মাউস
  • একসাথে অনেক অ্যাপ

মোবাইল

  • Android, iOS
  • টাচ, ব্যাটারি
  • একটা অ্যাপ সামনে

দুটোই OS, শুধু ব্যবহারের ধরন আলাদা।

🏪

অ্যাপ স্টোর = দোকান

অ্যাপ স্টোর শুধু দোকান না — এটা দেখে অ্যাপ নিরাপদ কি না, আপডেট দেয়, টাকা নেয়। ডেভেলপার আয়ের ১৫–৩০% স্টোরকে দিতে পারে।

সফটওয়্যার কীভাবে তৈরি হয়

সোর্স কোড থেকে ইনস্টলার

→
ডেভেলপার কোড লেখে (Python, Kotlin, Swift)।
→
Build করলে মেশিনের বোঝার মতো ফাইল হয়।
→
Installer বা App Store সেটা ফোনে বসায়।
→
চালু হলে OS মেমোরিতে লোড করে।
📖

Open source: রেসিপি সবার জন্য

কোড সবার জন্য খোলা। যে কেউ পড়তে, বদলাতে, উন্নত করতে পারে। Linux, Firefox, WordPress, Python — সব open source।

ফ্রি বনাম open source

ফ্রি

  • দাম শূন্য
  • কোড বন্ধ হতে পারে
  • ব্যবসার নিয়ম আলাদা

Open source

  • কোড দেখা যায়
  • নিজের মতো বদলানো যায়
  • লাইসেন্স মানতে হয়

ফ্রি মানেই open source নয়; open source মানেই ফ্রি নয়।

ফাইল আর ফোল্ডার

কম্পিউটারের আলমারি

Fileএকটা তথ্যের টুকরোছবি, ডকুমেন্ট, গান।
Folderফাইলের বাক্সএকই ধরনের ফাইল একসাথে রাখে।
Extensionফাইলের ধরন.jpg ছবি, .pdf ডকুমেন্ট, .mp4 ভিডিও।
GUIছবি-আইকনের ইন্টারফেসমাউসে ক্লিক করা যায়।

আপডেট কেন দরকার?

আপডেট শুধু নতুন ফিচার না — নিরাপত্তার তালা। পুরনো অ্যাপে ফাঁক থাকে, হ্যাকার সেটা ব্যবহার করে। তাই ফোন আর ব্রাউজার আপডেট রাখো।
