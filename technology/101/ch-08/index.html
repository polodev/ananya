ডেটাবেস = গোছানো লেজার

নাম, ফোন, অর্ডার, টাকা — সব ডেটা টেবিলে সাজানো থাকে। একসাথে অনেক মানুষ ব্যবহার করতে পারে, নিয়ম মানায়, আর দ্রুত খুঁজে দেয়।

টেবিলের চারটা শব্দ

table, row, column, primary key

Tableএকই ধরনের ডেটার তালিকাযেমন students।
Rowএকটা রেকর্ডএকজন ছাত্রের পুরো তথ্য।
Columnএকটা বৈশিষ্ট্যname, city, phone।
Primary keyপ্রতিটি সারির অনন্য পরিচয়id — দুইবার একই id নয়।

এক্সেল শিট

চেনা জিনিসএক্সেল
→
টেকের নামডেটাবেস

দেখতে একই — সারি আর কলাম। কিন্তু ডেটাবেসে অনেক ইউজার একসাথে কাজ করে, নিয়ম enforce করে, কোটি সারিতে দ্রুত খোঁজে, আর ভুল হলে ফিরিয়ে আনে।

🔎

SQL = ডেটার সাথে কথা বলার ভাষা

SELECT দিয়ে খোঁজো, INSERT দিয়ে যোগ করো, UPDATE দিয়ে বদলাও, DELETE দিয়ে মুছো। এই চারটা দিয়ে বেশিরভাগ কাজ শুরু।

প্রথম SQL

একটা টেবিল থেকে শহর অনুযায়ী নাম

SELECT name, city
FROM students
WHERE city = 'Dhaka'
ORDER BY name;
outputname | city -------+------- Mitu | Dhaka Rafi | Dhaka

SQL পড়া যায় ইংরেজির মতো: students থেকে name, city নাও যেখানে city Dhaka।

SQL বনাম NoSQL

SQL (relational)

  • টেবিল, সারি, কলাম
  • স্কিমা আগে ঠিক হয়
  • ব্যাংক, অর্ডার, হিসাব

NoSQL

  • ডকুমেন্ট, key-value
  • স্কিমা নমনীয়
  • লগ, ক্যাটালগ, দ্রুত বদলানো

NoSQL মানে SQL-এর শত্রু নয় — অন্য ধরনের কাজের জন্য অন্য ধরনের ডেটাবেস।

🍴

Fork কী? রেসিপির কপি নিয়ে নিজের রেস্টুরেন্ট

Fork মানে একটা প্রজেক্টের কোড কপি করে আলাদা দলে নিজের মতো এগিয়ে নেওয়া। মূল দল আর fork দল আলাদা সিদ্ধান্ত নেয়। MariaDB হলো MySQL-এর এমন একটা fork।
