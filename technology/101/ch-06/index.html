প্রোগ্রামিং = কম্পিউটারকে ধাপে ধাপে কাজ বলা

কম্পিউটার নিজে কিছু বোঝে না। তুমি একটা নির্দেশনার তালিকা দাও, সে এক এক করে চালায়। এই তালিকাই প্রোগ্রাম।

চা বানানোর অ্যালগরিদম

1
শুরু

পানি নাও, চুলা জ্বালো।

2
ধাপ ১

পানি ফুটলে চা পাতা দাও।

3
ধাপ ২

চিনি আর দুধ দাও।

4
ধাপ ৩

ছেঁকে কাপে ঢালো।

5
শেষ

গরম চা তৈরি।

চারটা শব্দ

algorithm, code, bug, debug

Algorithmকাজের ধাপে ধাপে পরিকল্পনাভাষা নয়, চিন্তার ক্রম।
Codeকম্পিউটারকে লেখা নির্দেশনাPython, JavaScript, C — বিভিন্ন ভাষায়।
Bugপ্রোগ্রামের ভুলভুল ফল, ক্র্যাশ, আটকে যাওয়া।
Debugভুল খুঁজে ঠিক করাerror message পড়া, ধাপে ধাপে পরীক্ষা।
👩‍🍳

কোড লেখা = রেসিপি লেখা

রেসিপিতে ‘একটু লবণ’ লেখা যায়, কোডে যায় না। কম্পিউটার জানে না ‘একটু’ কত। তাই প্রতিটি ধাপ স্পষ্ট, ক্রম ঠিক, আর প্রতিটি শর্ত লেখা লাগে।

Compiler বনাম Interpreter

Compiler

  • পুরো বই একবারে অনুবাদ
  • আগে ভুল ধরা পড়ে
  • C, C++, Go, Rust

Interpreter

  • লাইন ধরে ধরে অনুবাদ
  • চালাতে চালাতে ভুল ধরা
  • Python, JavaScript, PHP

দুটোই শেষে CPU-র বোঝার ভাষায় পৌঁছায়।

সোর্স কোড থেকে অ্যাপ

1
Source

তুমি hello.c লেখো।

2
Compiler

সেটাকে মেশিন কোডে বদলায়।

3
Linker

দরকারি library জুড়ে দেয়।

4
Executable

চালানোর মতো ফাইল তৈরি।

আরও চারটা

source code, syntax, runtime, library

Source codeতুমি যা লেখোমানুষের পড়ার মতো।
Syntaxভাষার ব্যাকরণভুল বন্ধনী বা কমা হলে error।
Runtimeপ্রোগ্রাম চলার সময়চলার সময় যা ঘটে।
Libraryআগেই বানানো কোডের ভাণ্ডারনিজে সব লিখতে হয় না।
🐞

বাগ = ভুল, কিন্তু কম্পিউটার অভিমান করে না

error message ভয়ের জিনিস না — সে তোমাকে বলে কোথায় আটকেছে। লাইন নম্বর পড়ো, শেষ থেকে শুরু করো, একটা একটা করে বদলাও।

প্রথম প্রোগ্রামের চারটা অংশ

সব ভাষায় এই কাঠামো ফিরে আসে

→
ইনপুট: ব্যবহারকারীর কাছ থেকে মান নাও।
→
Variable: মানটা একটা নামে রাখো।
→
Decision: শর্ত মিললে এক পথ, না মিললে অন্য পথ।
→
Output: ফলটা দেখাও।
💾

Git = সময়ের সেভ পয়েন্ট

গেমে যেমন সেভ পয়েন্ট থাকে, Git-এ তেমনি commit থাকে। ভুল করলে পুরনো commit-এ ফেরা যায়। একই ফাইলের বিভিন্ন সংস্করণ গুলিয়ে ফেলার ভয় কমে।

Git-এর চারটা শব্দ

Git, GitHub, repository, commit

Gitভার্সন কন্ট্রোল সিস্টেমফাইলের ইতিহাস রাখে।
GitHubGit রিপোজিটরি রাখার ওয়েবসাইটসহযোগিতা আর পোর্টফোলিও।
Repositoryএকটা প্রজেক্টের ফাইল আর ইতিহাসrepo বলেও ডাকা হয়।
Commitএকটা সেভ পয়েন্টকী বদলালো, তার বার্তা থাকে।
🌍

সব ভাষা একই কাজ করে, ভিন্ন স্বাদ

Python পড়তে সহজ, C মেশিনের কাছে, JavaScript ব্রাউজারে, SQL ডেটার সাথে। একটা ভাষা শিখলে ধারণাগুলো অন্য ভাষায় সহজে যায়।
