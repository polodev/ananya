কম্পিউটার বোঝে শুধু মেশিন কোড

CPU-র নির্দেশনা আসলে সংখ্যা। মানুষের পড়ার সুবিধার জন্য আমরা উঁচু স্তরের ভাষা লিখি, তারপর সেটাকে মেশিন কোডে বদলাই।

ভাষার স্তর

1
Machine code

০ আর ১ — CPU সরাসরি বোঝে।

2
Assembly

সংক্ষিপ্ত নাম, যেমন MOV, ADD।

3
C

মেশিনের কাছাকাছি, তবু পড়া যায়।

4
Python / JS

আরও সহজ, আরও লুকানো।

High-level বনাম Low-level

High-level

  • পড়তে-লিখতে সহজ
  • মেমোরি নিজে সামলায়
  • Python, JavaScript, PHP

Low-level

  • হার্ডওয়্যারের কাছে
  • মেমোরি নিজে সামলাতে হয়
  • C, Assembly

উঁচু মানে ‘ভালো’ নয় — মানে মানুষের থেকে দূরে নয়।

চারটা বড় নাম

C, C++, Java, Python

C১৯৭২, Dennis RitchieUnix, OS, embedded; মেমোরির নিয়ন্ত্রণ।
C++১৯৭৯, Bjarne StroustrupC + object-oriented; গেম, browser, বড় সিস্টেম।
Java১৯৯৫, James Gosling‘একবার লেখো, সব জায়গায় চালাও’; ব্যাংক, Android।
Python১৯৯১, Guido van Rossumপড়তে সহজ; data, AI, scripting।

আরও চারটা

JavaScript, PHP, Go, Rust

JavaScript১৯৯৫, Brendan Eichব্রাউজারের ভাষা; Node.js দিয়ে সার্ভারও।
PHP১৯৯৫, Rasmus Lerdorfসার্ভার-সাইড ওয়েব; WordPress।
Go২০০৯, Googleসহজ, দ্রুত; cloud আর network service।
Rust২০১০, Mozillaমেমোরি নিরাপত্তা; সিস্টেম প্রোগ্রামিং।

Compiled বনাম Interpreted

Compiled

  • আগে পুরোটা অনুবাদ
  • চালাতে দ্রুত
  • C, Go, Rust

Interpreted

  • চলার সময় অনুবাদ
  • শিখতে-বদলাতে সহজ
  • Python, JavaScript, PHP

আজকের অনেক ভাষা দুটোর মিশ্রণ — আগে bytecode, পরে JIT।

🇨

C: মেশিনের কাছাকাছি, তবু পড়া যায়

১৯৭২ সালে Dennis Ritchie Bell Labs-এ C বানান। Unix অপারেটিং সিস্টেম C-তে লেখা। আজও Linux kernel, এমবেডেড সিস্টেম, ডেটাবেস — সবখানে C।

🐍

Python: পড়তে সহজ, AI-এর প্রিয়

Guido van Rossum ১৯৯১ সালে Python বানান। স্পষ্ট syntax, বিশাল library। data analysis, machine learning, automation — নতুনদের প্রথম ভাষা হিসেবে জনপ্রিয়।

🟨

JavaScript: ব্রাউজারের ভাষা

Brendan Eich ১৯৯৫ সালে Netscape-এ মাত্র কয়েক দিনে JavaScript বানান। আজ প্রতিটি ওয়েবসাইটে JavaScript আছে; Node.js দিয়ে সার্ভারেও চলে।

🐘

PHP: ওয়েবের পুরনো কাজের ঘোড়া

Rasmus Lerdorf ১৯৯৫ সালে PHP বানান। WordPress, Wikipedia, অসংখ্য ছোট-বড় সাইট PHP-তে চলে। পুরনো হলেও এখনও বিশাল।

🏗️

Java, Go, Rust: বড় সিস্টেমের ভাষা

Java ব্যাংক আর Android-এ, Go cloud service-এ, Rust নিরাপদ সিস্টেমে। ভাষা বেছে নেওয়া মানে কাজের ধরন বেছে নেওয়া।

যেগুলো প্রোগ্রামিং ভাষা নয়

SQL, HTML, CSS, Bash

SQLডেটাবেসের প্রশ্নের ভাষাডেটা খোঁজা, যোগ, বদলানো।
HTMLপেজের কাঠামোমার্কআপ, প্রোগ্রামিং নয়।
CSSপেজের সাজরঙ, ফন্ট, layout।
BashLinux-এর কমান্ড ভাষাফাইল আর সিস্টেম চালানো।
🍳

ভাষা শেখা = রান্না শেখা

একটা রান্না শিখলে অন্য রেসিপি সহজ হয়। একইভাবে variable, loop, function, condition — সব ভাষায় ফিরে আসে। প্রথম ভাষায় গভীরে যাও, বাকিগুলো দ্রুত আসবে।
