Cloud, servers and hosting

‘ক্লাউড’ আকাশে কিছু নেই — এটা অন্যের কম্পিউটার, ভাড়ায়। আজ হোস্টিংয়ের দুনিয়া চিনবে।

ক্লাউড = অন্যের কম্পিউটার, ভাড়ায়

তুমি সার্ভার কিনে বাসায় রাখো না। AWS, Hetzner বা Hostinger-এর data center-এ ভাড়া নাও। বিদ্যুৎ, কুলিং, ইন্টারনেট — তারা সামলায়।

চারটা শব্দ

server, data center, VPS, shared hosting

Serverসার্ভিস দেওয়া কম্পিউটারওয়েবসাইট, অ্যাপ, ডেটাবেস চলে।
Data centerসার্ভারের বাড়িবিদ্যুৎ, কুলিং, নিরাপত্তা।
VPSভার্চুয়াল প্রাইভেট সার্ভারএকটা সার্ভারের ভেতরে তোমার আলাদা অংশ।
Shared hostingএকই সার্ভার, অনেক ওয়েবসাইটসস্তা, কিন্তু প্রতিবেশীর ভিড়ে ধীর হতে পারে।

হোস্টিংয়ের ধরন

সস্তা থেকে দামি

  • Shared — একই সার্ভার ভাগ
  • VPS — নিজের অংশ
  • Dedicated — পুরো সার্ভার

নিয়ন্ত্রণ

  • Shared — কম
  • VPS — মাঝারি
  • Cloud — প্রয়োজনে বাড়ে-কমে

শুরুতে shared, বাড়লে VPS, বড় হলে cloud।

ডোমেইন আর ঠিকানা

domain, DNS, SSL, CDN

Domainতোমার সাইটের নামexample.com — ভাড়া নিতে হয়।
DNSনামকে IP-তে বদলায়nameserver সেট করতে হয়।
SSLHTTPS-এর তালাLet's Encrypt দিয়ে ফ্রি পাওয়া যায়।
CDNকাছের সার্ভারে কপিছবি-ফাইল দ্রুত পৌঁছায়।

IaaS, PaaS, SaaS

ভাড়ার তিনটা ধাপ

IaaSকাঁচা সার্ভার ভাড়াসব নিজে সামলাও — AWS EC2, Linode।
PaaSঅ্যাপ চালানোর প্ল্যাটফর্মসার্ভার কম সামলাও — Heroku, Render, Vercel।
SaaSতৈরি সফটওয়্যার ব্যবহারকিছুই সামলাতে হয় না — Gmail, Canva, Shopify।
💳

ক্লাউড বিল কীভাবে বাড়ে?

Compute (CPU/GPU), storage, bandwidth, database — প্রতিটা আলাদা দাম। ভুলে সার্ভার চালু রাখলে বিল বাড়ে। তাই budget alert আর usage dashboard দেখো।

✓
ক্লাউড = ভাড়া করা কম্পিউটার।
✓
Shared সস্তা, VPS নিয়ন্ত্রণ বেশি, cloud নমনীয়।
✓
AWS বড়, Linode/Hetzner/Hostinger সাশ্রয়ী।
✓
ডোমেইন + DNS + SSL = সাইট অনলাইনে।
