নিরাপত্তা = অভ্যাসের সেট

শক্ত পাসওয়ার্ড, 2FA, আপডেট, ব্যাকআপ, সন্দেহ — এই পাঁচটা ৯০% ঝামেলা কমায়।

চারটা অভ্যাস

password manager, 2FA, update, backup

Password managerপ্রতিটা সাইটের আলাদা পাসওয়ার্ডমনে রাখার দরকার নেই।
2FAদুই ধাপের যাচাইপাসওয়ার্ড চুরি হলেও বাঁচায়।
Updateনিরাপত্তার patchপুরনো সফটওয়্যার = ফাঁক।
Backupআলাদা কপি3-2-1 নিয়ম।
🎣

Phishing চেনার উপায়

ভয় দেখানো বার্তা, ভুল ঠিকানা, ‘তাড়াতাড়ি করো’, OTP চাওয়া, অচেনা লিংক। লিংকে ঢোকার আগে ঠিকানা পড়ো।

📵

OTP কাউকে দিও না

ব্যাংক, bKash, Nagad, Facebook — কেউ ফোনে OTP চাইবে না। কেউ চাইলে ধরে নাও প্রতারণা।

ব্যাকআপের তিনটা নিয়ম

3-2-1, offline, restore test

3-2-1৩ কপি, ২ মাধ্যম, ১ অন্য জায়গায়ফোন + ক্লাউড + ডিস্ক।
Offlineইন্টারনেট ছাড়া কপিransomware থেকে বাঁচায়।
Restore testফেরানো পরীক্ষাব্যাকআপ আছে মানেই কাজ করবে না।
Versioningপুরনো সংস্করণভুল ডিলিট থেকে বাঁচায়।
🔑

পাসওয়ার্ডের নিয়ম

লম্বা (১৬+ অক্ষর), অনন্য, আর password manager-এ রাখো। ‘১১২২৩৩’ বা জন্মতারিখ নয়। একই পাসওয়ার্ড সব জায়গায় নয়।

📱

ফোন/ল্যাপটপ হারালে

Find My/devices, remote wipe, ব্যাংক অ্যাকাউন্ট বন্ধ, পাসওয়ার্ড বদল, 2FA রিভিউ — আগেই সেটআপ রাখো।
