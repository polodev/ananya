মূল ধারণা
💾

Git = কোডের টাইম মেশিন

প্রতিটি পরিবর্তন একটা commit। ভুল হলে পুরনো commit-এ ফেরা যায়। GitHub সেই ইতিহাস অনলাইনে রাখে।

Git-এর পাঁচ ধাপ

1
init

নতুন repo বানাও।

2
add

পরিবর্তন স্টেজ করো।

3
commit

সেভ পয়েন্ট বানাও।

4
branch

আলাদা লাইনে কাজ করো।

5
merge

কাজ জোড়া লাগাও।

চারটা শব্দ

repository, commit, branch, merge

Repositoryপ্রজেক্ট + ইতিহাস.git ফোল্ডার।
Commitসেভ পয়েন্টবার্তা সহ।
Branchআলাদা কাজের লাইনfeature branch।
Mergeশাখা জোড়াmain-এ ফেরা।
প্রথম repo

init → add → commit

mkdir my-app && cd my-app
git init
echo "# My App" > README.md
git add README.md
git commit -m "first commit"

git init শুধু একবার; প্রতিবার বদলের পর add+commit।

Branch ও merge

আলাদা লাইনে কাজ

git checkout -b feature-login
# কোড বদলাও
git add .
git commit -m "add login"
git checkout main
git merge feature-login

Branch-এ কাজ শেষে main-এ merge।

GitHub-এর চারটা শব্দ

remote, push, pull, pull request

Remoteঅনলাইনে repoorigin।
Pushনিজের commit পাঠাওgit push।
Pullঅন্যের commit আনোgit pull।
Pull requestmerge করার অনুরোধreview হয়।
✍️

Commit বার্তা ভালো লেখো

‘fix’ নয়, ‘fix login button on mobile’। ভবিষ্যতে তুমি নিজেই বুঝবে কী বদলেছিল।

⚔️

Merge conflict

দুইজনে একই লাইনে বদলালে Git বুঝতে পারে না কোনটা রাখবে। তখন conflict mark দেখে নিজে ঠিক করো, তারপর add+commit।
