টার্মিনাল = কম্পিউটারের সাথে লেখা দিয়ে কথা

মাউসে ক্লিক না করে কমান্ড লিখে ফাইল, ফোল্ডার, প্রোগ্রাম চালাও। সার্ভারে মাউস নেই, তাই এটা জানা লাগে।

🐧

সার্ভারে Linux কেন?

ফ্রি, হালকা, স্থিতিশীল, নিরাপদ, আর স্ক্রিপ্ট করা সহজ। Android-এর ভেতরেও Linux, AWS-এর বেশিরভাগ সার্ভার Linux।

চারটা মৌলিক কমান্ড

pwd, ls, cd, cat

pwdআমি কোথায়বর্তমান ফোল্ডার দেখায়।
lsকী আছেফাইল-ফোল্ডার তালিকা।
cdফোল্ডার বদলাওcd projects।
catফাইল দেখাওcat notes.txt।
প্রথম টার্মিনাল সেশন

ফোল্ডার ঘোরা

pwd
ls
mkdir my-site
cd my-site
ls -la

mkdir নতুন ফোল্ডার, -la লুকানো ফাইলসহ দেখায়।

ফাইল সামলানোর চারটা কমান্ড

cp, mv, rm, touch

cpকপিcp a.txt b.txt।
mvসরানো/নাম বদলmv old.txt new.txt।
rmমুছে ফেলাrm file.txt — সাবধান!
touchখালি ফাইলtouch index.html।
☠️

rm -rf = বড় বিপদ

rm -rf folder পুরো ফোল্ডার চিরতরে মুছে দেয়, recycle bin নেই। কমান্ড চালানোর আগে পথটা দুবার পড়ো।

অনুমতির চারটা শব্দ

user, group, chmod, sudo

Userতুমি কেনিজের ফাইল।
Groupএকদল ব্যবহারকারীটিম অ্যাক্সেস।
chmodঅনুমতি বদলread/write/execute।
sudoadmin ক্ষমতাসাবধানে ব্যবহার করো।
SSH দিয়ে সার্ভারে ঢোকা

দূরের কম্পিউটার

ssh root@203.0.113.10
# তারপর সার্ভারে:
apt update
apt install nginx

SSH দিয়ে দূরের Linux সার্ভারে লগইন করা যায়।

📦

Package manager = অ্যাপ স্টোর

Ubuntu/Debian-এ apt, CentOS/RHEL-এ dnf, macOS-এ brew। কমান্ড দিয়েই সফটওয়্যার ইনস্টল, আপডেট, রিমুভ।

নতুনদের চারটা অভ্যাস

টার্মিনালে নিরাপদে চলার জন্য

→

→
