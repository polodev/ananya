সাইট অনলাইনে = নাম + বাসা + ঠিকানা + তালা

ডোমেইন, হোস্টিং, DNS, SSL — চারটা জিনিস ঠিক থাকলে সাইট বিশ্বজুড়ে দেখা যায়।

ডিপ্লয়ের পাঁচ ধাপ

Code

2

সার্ভার/প্ল্যাটফর্ম বাছো।

3

ফাইল বা Git push।

4
DNS

ডোমেইন জোড়ো।

5
SSL

HTTPS চালু।

চারটা শব্দ

registrar, nameserver, A record, CNAME

Registrarডোমেইন বিক্রেতাNamecheap, Cloudflare।
NameserverDNS কোথায় চলবেহোস্টিং বা Cloudflare।
A recordনাম → IPv4মূল ডোমেইনে।
CNAMEনাম → অন্য নামwww → root।
📄

Static সাইট ডিপ্লয় করা সহজ

HTML/CSS/JS শুধু ফাইল — Vercel, Netlify, GitHub Pages-এ drag বা Git push করলেই অনলাইনে। সার্ভার সামলাতে হয় না।

ডিপ্লয়ের চারটা প্ল্যাটফর্ম

Static / frontend

  • Vercel, Netlify
  • Git push = deploy
  • ফ্রি tier

VPS / cloud

  • Linode, Hetzner, AWS
  • নিজে সব সামলাও
  • বেশি নিয়ন্ত্রণ

শুরুতে static, পরে দরকারে VPS।

একটা স্ট্যাটিক সাইট

index.html

<!doctype html>
<html>
<head><title>My Site</title></head>
<body>
  <h1>হ্যালো!</h1>
</body>
</html>

এই ফাইলটা আপলোড করলেই একটা পেজ তৈরি।

🖱️

cPanel আর WordPress

shared hosting-এ cPanel দিয়ে ফাইল, ইমেইল, ডেটাবেস সামলানো যায়। WordPress এক ক্লিকে বসানো যায়।

SSL-এর চারটা শব্দ

certificate, Let's Encrypt, redirect, mixed content

Certificateসার্ভারের পরিচয়কে দিয়েছে দেখো।
Let's Encryptফ্রি স্বয়ংক্রিয়৯০ দিনে নবায়ন।
RedirectHTTP → HTTPSসব ট্রাফিক নিরাপদ।
Mixed contentHTTPS-এ HTTP ফাইলসতর্কতা দেয়।
⏳

DNS propagation

nameserver বদলালে কিছু সময় লাগে। TTL কমিয়ে আগে পরীক্ষা করো, তারপর বদলাও। সবসময় ৪৮ ঘণ্টা লাগে না — সাধারণত মিনিট।
