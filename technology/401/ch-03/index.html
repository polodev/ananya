মূল ধারণা
🧱

C-তে প্রতিটি বাইটের একটা ঠিকানা

মেমোরি হলো বিশাল একটা সারি, প্রতিটি ঘরের একটা নম্বর। variable সেই ঘরে থাকে।

চারটা শব্দ

bit, byte, address, stack

Bit০ বা ১সবচেয়ে ছোট একক।
Byte৮ বিটমেমোরির একক।
Addressমেমোরির নম্বরpointer এটা ধরে।
Stackফাংশনের কাজের জায়গাlocal variable এখানে।
sizeof দিয়ে মাপো

টাইপ কত বাইট

#include <stdio.h>

int main(void) {
    printf("int: %zu\n", sizeof(int));
    printf("double: %zu\n", sizeof(double));
    printf("char: %zu\n", sizeof(char));
    return 0;
}
outputint: 4 double: 8 char: 1

আকার প্ল্যাটফর্ম অনুযায়ী বদলাতে পারে।

মূল টাইপগুলো

সংখ্যা

  • int — পূর্ণসংখ্যা
  • float — দশমিক
  • double — বেশি নির্ভুল

অন্য

  • char — অক্ষর
  • void — কিছু নেই
  • struct — নিজের টাইপ

টাইপ ঠিক করলে মেমোরি কত লাগবে, সেটাও ঠিক হয়।

➕

Signed বনাম unsigned

int ঋণাত্মক হতে পারে, unsigned int শুধু শূন্য বা ধনাত্মক। সীমা ছাড়ালে wraparound হয় — ভুল হিসাবের বড় উৎস।

Overflow দেখো

সীমার বাইরে

#include <stdio.h>
#include <limits.h>

int main(void) {
    int max = INT_MAX;
    printf("%d\n", max);
    printf("%d\n", max + 1);
    return 0;
}
output2147483647 -2147483648

Signed overflow C-তে undefined behavior; এটা শুধু উদাহরণ।

ফাংশন call আর local variable।

Stack-এ ফাংশন

call হলে কী হয়

#include <stdio.h>

int add(int a, int b) {
    int sum = a + b;
    return sum;
}

int main(void) {
    printf("%d\n", add(3, 4));
    return 0;
}
output7

প্রতিটি call-এ নতুন stack frame তৈরি হয়।

📒

Stack = খাতার পাতা

ফাংশন ডাকলে নতুন পাতা ওপরে বসে, শেষ হলে পাতা ছিঁড়ে যায়। তাই local variable ফাংশন শেষ হলে আর থাকে না।

Binary আর hex

মেমোরি দেখার ভাষা

#include <stdio.h>

int main(void) {
    int x = 42;
    printf("dec: %d\n", x);
    printf("hex: 0x%X\n", x);
    printf("oct: %o\n", x);
    return 0;
}
outputdec: 42 hex: 0x2A oct: 52

42 = 0x2A — একই মান, ভিন্ন ভাষায়।
