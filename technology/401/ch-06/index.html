C = সিস্টেমের ভাষা

অপারেটিং সিস্টেম, ডেটাবেস, embedded device, compiler, interpreter — যেখানে হার্ডওয়্যারের কাছাকাছি কাজ দরকার, সেখানে C।

চারটা জায়গা

kernel, embedded, database, runtime

KernelOS-এর মূল অংশLinux-এর বড় অংশ C।
Embeddedছোট ডিভাইসমাইক্রোকন্ট্রোলার, রিমোট, গাড়ি।
Databaseডেটা রাখার ইঞ্জিনSQLite পুরোটাই C।
Runtimeভাষার ইঞ্জিনPython interpreter C-তে।

Python-এর ভেতরেও C

CPython interpreter C-তে লেখা। তুমি Python-এ list ব্যবহার করলে নিচে C-এর অ্যারে আর মেমোরি ম্যানেজমেন্ট চলছে।

⚠️

C বিপজ্জনক, কিন্তু দরকারি

C তোমাকে মেমোরির পুরো নিয়ন্ত্রণ দেয়, তাই ভুলের শাস্তিও বড়। তাই নিয়ম, টেস্ট, আর tool (Valgrind, sanitizer) দরকার।
