মূল ধারণা
🧩

struct = নিজের বানানো টাইপ

একজন ইউজারের নাম, বয়স, শহর — একসাথে রাখো। C-তে struct দিয়ে নতুন টাইপ বানায়।

প্রথম struct

নাম আর বয়স

#include <stdio.h>

struct User {
    char name[20];
    int age;
};

int main(void) {
    struct User u = {"Mitu", 21};
    printf("%s %d\n", u.name, u.age);
    return 0;
}
outputMitu 21

struct User এখন একটা টাইপের মতো ব্যবহার করা যায়।

চারটা শব্দ

struct, typedef, heap, malloc

structকয়েকটা মানের প্যাকেটনিজের টাইপ।
typedefনামের ছোট রূপtypedef struct User User;
Heapচাহিদা অনুযায়ী মেমোরিপ্রোগ্রাম চলার সময় বাড়ে।
mallocheap থেকে মেমোরি নেওয়াশেষে free করতে হয়।
malloc আর free

heap থেকে মেমোরি নাও

#include <stdlib.h>

int main(void) {
    int *nums = malloc(3 * sizeof(int));
    if (!nums) return 1;

    nums[0] = 10;
    return 0;
}

malloc ব্যর্থ হলে NULL; সফল হলে free করতে হবে।

malloc আর free

ব্যবহার ও ফেরত দাও

nums[1] = 20;
printf("%d\n", nums[1]); // 20

free(nums);
nums = NULL;

একই প্রোগ্রামের পরের অংশ — nums আগের স্লাইডে malloc করা।

Heap allocation

1
চাও

malloc(size)।

2
পাও

ঠিকানা ফেরত, বা NULL।

3

লেখো/পড়ো।

4

free(ptr)।

💧

Memory leak = ভাড়া ঘর না ছাড়া

বারবার malloc করে free না করলে প্রোগ্রাম চলতে চলতে মেমোরি খায়। দীর্ঘদিন চলা সার্ভারে এটা বড় সমস্যা।

Dynamic array

প্রয়োজন মতো বড়

#include <stdlib.h>

int *make_numbers(int n) {
    int *a = malloc(n * sizeof(int));
    if (!a) return NULL;
    for (int i = 0; i < n; i++) a[i] = i * i;
    return a;
}

ফাংশন মেমোরি বানিয়ে ঠিকানা ফেরত দেয়; কল করা দল free করবে।

☠️

Double free আর use-after-free

একই pointer দুবার free করলে বা free করার পরে ব্যবহার করলে বিপদ। free করার পরে pointer-এ NULL রাখো।

মেমোরির চারটা নিয়ম

মালিকানা স্পষ্ট রাখো

→
যে malloc করে, সে free করে।
→
free করার পরে NULL রাখো।
→
সীমার বাইরে লিখো না।
→
sizeof দিয়ে সাইজ হিসাব করো।
Linked list node

struct + pointer

struct Node {
    int value;
    struct Node *next;
};

// newNode = malloc(sizeof(struct Node));
// newNode->value = 42;
// newNode->next = NULL;

নিজের struct-এর pointer রাখতে পারে — এটাই linked list।
