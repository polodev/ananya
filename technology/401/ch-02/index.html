মূল ধারণা
📄

C একটি compiled ভাষা

তুমি .c ফাইলে লেখো, compiler সেটাকে মেশিন কোডে বদলায়, linker executable বানায়। তারপর সেটা সরাসরি CPU-তে চলে।

hello.c-এর যাত্রা

1
Preprocess

#include আর #define খোলে।

2
Compile

C কোড assembly-তে যায়।

3
Assemble

assembly machine code হয়।

4
Link

libc-এর সাথে জোড়া লাগে।

5
Run

executable চালু হয়।

hello.c

প্রথম C প্রোগ্রাম

#include <stdio.h>

int main(void) {
    printf("Hello, Anonna!\n");
    return 0;
}
outputHello, Anonna!

#include হেডার আনে, main প্রোগ্রামের শুরু, return 0 সফলতা।

কম্পাইল ও চালাও

টার্মিনালে

gcc hello.c -o hello
./hello
outputHello, Anonna!

-o hello মানে output ফাইলের নাম hello।

চারটা শব্দ

preprocessor, compiler, assembler, linker

Preprocessor# দিয়ে শুরু লাইন সামলায়#include, #define।
CompilerC → assemblygcc -S।
Assemblerassembly → objecthello.o।
Linkerobject + library → executablelibc জোড়ে।
⚠️

Error বনাম Warning

Error হলে প্রোগ্রাম তৈরি হয় না। Warning হলে হয়, কিন্তু বিপদ থাকতে পারে। Warning উপেক্ষা করো না — -Wall -Wextra দিয়ে সব দেখো।

টাইপ আর printf

ছোট পরীক্ষা

#include <stdio.h>

int main(void) {
    int age = 21;
    double price = 99.50;
    char grade = 'A';
    printf("%d %.2f %c\n", age, price, grade);
    return 0;
}
output21 99.50 A

%d int, %.2f double, %c char।

প্রোগ্রামের চারটা অংশ

header, main, statement, return

Headerবাইরের ফাংশনের ঘোষণাstdio.h, stdlib.h।
mainশুরুর ফাংশনOS এখান থেকেই চালায়।
Statementএকটা নির্দেশনাপ্রতিটির শেষে ;।
Returnmain থেকে OS-কে ফল0 = সফল।
🕳️

Undefined behavior: C-এর গোপন ফাঁদ

অ্যারের বাইরে পড়া, free করা pointer আবার ব্যবহার, signed overflow — এগুলো C-তে ‘undefined’। যা খুশি হতে পারে। তাই নিয়ম কঠিন।
