High-level vs low-level languages

JavaScript লিখলে তুমি মেশিন দেখো না। C-তে মেশিনের অনেক কাছাকাছি যাবে। আজ সেই দূরত্বটা বুঝবে।

মূল ধারণা
🪜

প্রতিটি ভাষা মেশিন থেকে একধাপ দূরে

CPU বোঝে শুধু মেশিন কোড। তার ওপরে assembly, তার ওপরে C, তার ওপরে Python/JavaScript। ওপরের ভাষা সহজ, নিচের ভাষা বেশি নিয়ন্ত্রণ দেয়।

ভাষার সিঁড়ি

1
Machine code

০/১ — CPU সরাসরি বোঝে।

2
Assembly

MOV, ADD — মানুষের পড়ার মতো নাম।

3
C

struct, pointer, function — মেশিনের কাছে।

4
Python / JS

মেমোরি লুকানো, পড়তে সহজ।

High-level বনাম Low-level

High-level

  • মেমোরি নিজে সামলায়
  • এক লাইনে অনেক কাজ
  • Python, JS, PHP

Low-level

  • মেমোরি নিজে সামলাও
  • হার্ডওয়্যারের নিয়ন্ত্রণ
  • C, Assembly

‘নিচু’ মানে খারাপ নয় — মানে মেশিনের কাছে।

চারটা অনুবাদক

compiler, assembler, linker, interpreter

CompilerC → assembly/machine codegcc, clang।
Assemblerassembly → machine codeas।
Linkerঅংশগুলো জোড়া দেয়libc, অন্য object file।
Interpreterলাইন ধরে চালায়Python, JavaScript।

টেকের নামকোড

Python হলো নকশার সহজ ভাষা — ‘একটা জানালা বসাও’। C হলো ইট, সিমেন্ট, মাপ — তুমি নিজে বলো জানালা কোথায়, কত বড়, কীভাবে বসবে।

🇨

C কেন এখনও টিকে আছে?

১৯৭২ সালে বানানো ভাষা, তবু Linux kernel, SQLite, Python interpreter, embedded device — সবখানে C। কারণ: ছোট, দ্রুত, হার্ডওয়্যারের নিয়ন্ত্রণ।

সিস্টেমের চারটা শব্দ

ABI, libc, syscall, kernel

ABIবাইনারির চুক্তিকীভাবে ফাংশন ডাকবে, register কীভাবে ব্যবহার হবে।
libcC-এর স্ট্যান্ডার্ড লাইব্রেরিprintf, malloc, strlen।
SyscallOS-কে অনুরোধফাইল পড়া, প্রসেস বানানো।
KernelOS-এর মূল অংশহার্ডওয়্যার সামলায়।

C-এর ছোট ইতিহাস

১৯৬৯–৭২

Bell Labs-এ Unix আর C।

১৯৭৮

‘The C Programming Language’ বই।

১৯৮৯

ANSI C স্ট্যান্ডার্ড।

১৯৯১

Linus Torvalds Linux kernel শুরু করেন।

আজ

OS, embedded, database, compiler — সবখানে C।

⚙️

JavaScript কোথায় C-এর ওপর দাঁড়িয়ে?

Chrome-এর V8 engine C++-এ লেখা, আর C++ C-এর ওপর। তুমি JS লিখলে নিচে C/C++ মেশিনের কাজ করছে।

মনে রাখো

✓
মেশিন কোড → assembly → C → Python/JS।
✓
C মেশিনের কাছে, Python মানুষের কাছে।
✓
Compiler আগে, interpreter চলার সময়।
✓
C এখনও OS, embedded, database-এ রাজত্ব করে।
