Chatbot বনাম API

Chatbot-এ তুমি টাইপ করো। API-তে তোমার অ্যাপ মডেলকে ডাকে, টোকেন অনুযায়ী দাম দেয়। একই মডেল, ভিন্ন দরজা।

মডেল বাছার চারটা মাপকাঠি

quality, cost, speed, privacy

Qualityউত্তরের গুণকাজ অনুযায়ী।
Costপ্রতি token দামবাজেট।
Speedকত দ্রুতchat vs batch।
Privacyডেটা কোথায় যায়সংবেদনশীল কাজে জরুরি।
📝

Benchmark = পরীক্ষার নম্বর

MMLU, coding, math, reasoning — নানা পরীক্ষায় মডেল তুলনা করা হয়। কিন্তু বাস্তব কাজে নিজের ডেটা দিয়ে পরীক্ষা করাই আসল।

Open বনাম Closed

Open weight

  • নিজে হোস্ট
  • ডেটা বাইরে যায় না
  • DeepSeek, Llama, Qwen

Closed API

  • সহজে শুরু
  • কোম্পানি চালায়
  • GPT, Claude, Gemini

সংবেদনশীল ডেটা হলে open weight বা enterprise চুক্তি দেখো।

🖼️

Multimodal = লেখা + ছবি + শব্দ

আজকের মডেল ছবি পড়তে, শব্দ শুনতে, ভিডিও বুঝতে পারে। তাই স্ক্রিনশট, ডায়াগ্রাম, রসিদ — সব ইনপুট হতে পারে।

🔄

মডেল প্রতিদিন বদলায়

সংস্করণ, দাম, সীমা — সব বদলায়। নাম মুখস্থ না করে শেখো: কাজ কী, কোন মডেল সেটায় ভালো, আর কীভাবে যাচাই করবে।
