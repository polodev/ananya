চারটা ব্যবহার

tutor, coding partner, editor, researcher

Tutorধাপে ধাপে ব্যাখ্যা‘শিশুকে বোঝানোর মতো’।
Coding partnerকোড লিখিয়ে বোঝালাইন ধরে ব্যাখ্যা চাও।
Editorলেখা পরিষ্কার করানিজের কণ্ঠ রাখো।
Researcherবিকল্প খোঁজাউৎস যাচাই করো।
AI দিয়ে কোড শেখা

প্রম্পট

এই JavaScript ফাংশনটা লাইন ধরে ব্যাখ্যা করো।
তারপর ৩টা edge case দেখাও যেখানে এটা ভুল হতে পারে।
শেষে একটা ছোট টেস্ট লিখে দাও।

ব্যাখ্যা + সমালোচনা + টেস্ট — তিনটাই চাও।

AI দিয়ে অ্যাপ বানানো

OpenAI/Claude/Gemini API দিয়ে chatbot, সারাংশ, অনুবাদ, শ্রেণিবিন্যাস — ছোট অ্যাপ দ্রুত বানানো যায়। API key গোপন রাখো, খরচের সীমা দাও।

API অ্যাপের চারটা অংশ

prompt, model, token limit, guardrail

Promptমডেলকে নির্দেশনাsystem + user।
Modelকোন মডেলদাম/গুণ দেখে।
Token limitকতটা ইনপুট/আউটপুটখরচ নিয়ন্ত্রণ।
Guardrailনিরাপত্তার নিয়মসংবেদনশীল বিষয় আটকানো।

AI দিয়ে শেখার সেরা উপায়

AI-কে দিয়ে নিজের উত্তর পরীক্ষা করাও, কিন্তু প্রথমে নিজে চেষ্টা করো। ‘উত্তর দাও’ নয়, ‘আমাকে জিজ্ঞেস করো’ — এতে শেখা বেশি।

AI-অ্যাপ বানানোর চারটা সতর্কতা

প্রোডাকশনে যাওয়ার আগে

→
API key সার্ভারে রাখো, ব্রাউজারে নয়।
→
খরচের সীমা আর rate limit দাও।
→
ব্যবহারকারীর ডেটা কী হবে লিখে রাখো।
→
ভুল উত্তরের জন্য fallback রাখো।
