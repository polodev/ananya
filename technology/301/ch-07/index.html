মূল ধারণা
🧾

অবজেক্ট = নাম-মানের প্যাকেট

একটা মানুষের নাম, বয়স, শহর — সব একসাথে। প্রতিটি নামকে বলে key, মানকে বলে value।

প্রথম অবজেক্ট

key আর value

const user = {
  name: "Mitu",
  age: 21,
  city: "Dhaka",
};

console.log(user.name);
console.log(user["city"]);
outputMitu Dhaka

ডট বা bracket — দুইভাবেই মান পাওয়া যায়।

চারটা শব্দ

property, method, nested, destructuring

Propertyএকটা key-valuename: "Mitu"
Methodঅবজেক্টের ভেতরের ফাংশনuser.greet()
Nestedঅবজেক্টের ভেতরে অবজেক্টuser.address.city
Destructuringkey ধরে মান বের করাconst { name } = user
Destructuring

সহজে মান বের করা

const user = { name: "Mitu", age: 21 };
const { name, age } = user;

console.log(name); // Mitu
console.log(age);  // 21

নাম মিলিয়ে মান বের করা যায়।

🌍

JSON = ডেটার বিশ্বভাষা

API থেকে ডেটা আসে JSON-এ। দেখতে JavaScript অবজেক্টের মতো, কিন্তু key-গুলো স্ট্রিং আর ফাংশন থাকে না। JSON.parse দিয়ে পড়ো, JSON.stringify দিয়ে লেখো।

JSON পার্স ও স্ট্রিং

পাঠানো-পাওয়া

const text = '{"name":"Mitu","age":21}';
const user = JSON.parse(text);
console.log(user.name); // Mitu

const back = JSON.stringify(user);
console.log(back);

API response সাধারণত স্ট্রিং, তাই parse করতে হয়।

অ্যারে বনাম অবজেক্ট

অ্যারে

  • ক্রম আছে
  • index দিয়ে
  • একই ধরনের তালিকা

অবজেক্ট

  • নাম আছে
  • key দিয়ে
  • একটা জিনিসের তথ্য

একটা ইউজারের তথ্য = object; অনেক ইউজার = array of objects।

অবজেক্টের অ্যারে

বাস্তব API ডেটা

const users = [
  { name: "Rafi", city: "Dhaka" },
  { name: "Mitu", city: "Sylhet" },
];

users.forEach(u => console.log(u.name, u.city));
outputRafi Dhaka Mitu Sylhet

প্রতিটি element একটা অবজেক্ট।

📋

অবজেক্ট বদলাতে হলে কপি

const copy = { ...user, age: 22 } — আগের মান রেখে নতুন অবজেক্ট। সরাসরি বদলালে অন্য জায়গার referenc-ও বদলে যায়।

Optional chaining

নেই কি না, নিরাপদে দেখো

const user = { name: "Mitu" };

console.log(user.address?.city); // undefined
console.log(user.name?.toUpperCase()); // MITU

?. মান নেই হলে error না দিয়ে undefined দেয়।
