Values, types and operators

JavaScript-এ 5 আর "5" এক নয়। আজ এই পার্থক্যটা পরিষ্কার হবে।

মূল ধারণা
🧮

প্রতিটি মানের একটা টাইপ আছে

সংখ্যা, লেখা, সত্য/মিথ্যা, কিছু নেই — টাইপ বলে দেয় মানটা দিয়ে কী করা যাবে।

চারটা টাইপ

string, number, boolean, object

Stringলেখা"hello", 'Dhaka'
Numberসংখ্যা10, 3.5, -2
Booleanসত্য/মিথ্যাtrue, false
Objectএকাধিক মানের প্যাকেটআজ পরে শিখবে।
typeof দিয়ে দেখো

টাইপ জানার উপায়

console.log(typeof "Mitu");   // string
console.log(typeof 21);       // number
console.log(typeof true);     // boolean
console.log(typeof undefined);// undefined

typeof বলে দেয় মানটা কোন ধরনের।

⚖️

== বনাম ===

== টাইপ বদলে মেলায়, === টাইপসহ মেলায়। "5" == 5 সত্য, কিন্তু "5" === 5 মিথ্যা। সবসময় === ব্যবহার করো।

কেন == বিপদ

টাইপ coercion

console.log("5" == 5);   // true  (ভয়ংকর!)
console.log("5" === 5);  // false (নিরাপদ)
console.log(0 == "");    // true
console.log(0 === "");   // false

নিয়ম: === আর !== ছাড়া comparison করো না।

অপারেটরের চারটা পরিবার

arithmetic, comparison, logical, assignment

Arithmeticহিসাব+ - * / %
Comparisonতুলনা=== !== > < >= <=
Logicalএকাধিক শর্ত&& || !
Assignmentমান রাখা= += -= ++
ছোট হিসাব

অপারেটর একসাথে

let price = 120;
let qty = 3;
let total = price * qty;
console.log(total);        // 360
console.log(total > 300);  // true

* আগে, তারপর তুলনা।

💡

Truthy আর falsy

JavaScript-এ শূন্য, খালি স্ট্রিং, null, undefined, NaN — এগুলো falsy। বাকি সব truthy, এমনকি "false" লেখাটাও।

স্ট্রিং জোড়া ও মেথড

লেখা নিয়ে কাজ

const first = "Anonna";
const last = "Akter";
console.log(first + " " + last);
console.log(first.length);
console.log(first.toUpperCase());

.length অক্ষর গোনে, .toUpperCase() বড় হাতের করে।

সংখ্যার চারটা ফাঁদ

এগুলো না জানলে অদ্ভুত বাগ হবে

→
0.1 + 0.2 হুবহু 0.3 নয় — floating point।
→
NaN মানে Not a Number।
→
parseInt("12px") → 12, কিন্তু Number("12px") → NaN।
→
টাকা গুনতে integer (পয়সা) ব্যবহার করো।
🔷

TypeScript = JavaScript + টাইপ

JavaScript-এ টাইপ ভুল করলে চলার সময় ধরা পড়ে। TypeScript আগেই ধরিয়ে দেয়। বড় প্রজেক্টে জনপ্রিয়, কিন্তু শেখা শুরু JavaScript দিয়েই।
