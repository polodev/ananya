অ্যারে: অনেকগুলো মান

Arrays: many values in one place

একটা নাম রাখতে variable, ১০০টা নাম রাখতে অ্যারে। আজ অ্যারের আসল শক্তি দেখবে।

মূল ধারণা

অ্যারে = এক লাইনে অনেক মান

প্রতিটি মানের একটা index থাকে, ০ থেকে শুরু। অ্যারে নিয়ে কাজ করার জন্য map, filter, reduce — তিনটা জাদু আছে।

প্রথম অ্যারে

index আর length

const names = ["Rafi", "Mitu", "Tanvir"];

console.log(names[0]);      // Rafi
console.log(names.length);   // 3
console.log(names[names.length - 1]); // Tanvir

index ০ থেকে শুরু; শেষ element-এর index length - 1।

চারটা শব্দ

index, length, push/pop, map

Indexকোন নম্বরে আছে০, ১, ২ …
Lengthকতগুলো আছেnames.length
push / popশেষে যোগ / শেষ থেকে বাদঅ্যারে বদলায়।
mapপ্রতিটি মান বদলে নতুন অ্যারেমূল অ্যারে থাকে।
map দিয়ে রূপান্তর

প্রতিটি সংখ্যার দ্বিগুণ

const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);

console.log(doubled); // [2, 4, 6, 8]
console.log(nums);    // [1, 2, 3, 4]

map নতুন অ্যারে ফেরত দেয়, মূলটা বদলায় না।

filter দিয়ে বাছাই

শুধু বড় সংখ্যা

const nums = [5, 12, 8, 20, 3];
const big = nums.filter(n => n > 10);

console.log(big); // [12, 20]

filter শর্ত সত্য হলে মানটা রাখে।

reduce দিয়ে যোগফল

অনেক মান থেকে এক মান

const cart = [120, 250, 80];
const total = cart.reduce((sum, price) => sum + price, 0);

console.log(total); // 450

0 হলো শুরুর মান; sum প্রতিবার জমা হয়।

map, filter, reduce, find

রূপান্তর / বাছাই

  • map — প্রতিটি বদলাও
  • filter — শর্তে রাখো
  • find — প্রথমটা খোঁজো

এক মান

  • reduce — সব জমিয়ে এক
  • forEach — শুধু ঘোরো
  • some/every — পরীক্ষা

অ্যারের ৯০% কাজ এই ছয়টা দিয়ে হয়।

দোকানের হিসাব

দাম আর পরিমাণ

const items = [
  { name: "চা", price: 20, qty: 2 },
  { name: "বিস্কুট", price: 50, qty: 1 },
];

const total = items.reduce((sum, item) => sum + item.price * item.qty, 0);
console.log(total); // 90
output90

প্রতিটি item-এর price × qty যোগ হচ্ছে।

অ্যারের চারটা ফাঁদ

এগুলো মনে রাখো

→
index ০ থেকে, ১ থেকে নয়।
→
length শেষ index নয় — এক কম।
→
sort() মূল অ্যারে বদলায়।
→

Spread: অ্যারের কপি

const copy = [...names] দিয়ে নতুন অ্যারে বানাও। const all = [...a, ...b] দিয়ে জোড়ো। মূল অ্যারে না বদলে নতুনটা বদলানো নিরাপদ।

কপি আর জোড়া

spread

const a = [1, 2];
const b = [3, 4];
const all = [...a, ...b];

console.log(all); // [1, 2, 3, 4]

Spread তিনটা ডট দিয়ে লেখা হয়।
