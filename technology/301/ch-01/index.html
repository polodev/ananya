প্রথম প্রোগ্রাম

console.log

console.log("হ্যালো, অনন্যা!");
console.log(2 + 3);
outputহ্যালো, অনন্যা! 5

console.log মানে: স্ক্রিনে দেখাও।

চারটা শব্দ

statement, expression, comment, console

Statementএকটা নির্দেশনাlet x = 5;
Expressionযার একটা মান হয়2 + 3 এর মান 5।
Commentমানুষের জন্য নোট// এটা কম্পিউটার পড়ে না
Consoleপরীক্ষার জানালাerror আর output দেখায়।
📦

Variable = নাম দেওয়া বাক্স

তুমি একটা মান বাক্সে রাখো, বাক্সের নাম দাও। পরে নাম দিয়ে মানটা ব্যবহার করো। JavaScript-এ let আর const দিয়ে বাক্স বানায়।

দুই ধরনের variable

let বদলায়, const বদলায় না

let city = "Dhaka";
city = "Sylhet";        // ঠিক আছে

const pi = 3.1416;
// pi = 3;              // error!

যেটা বদলাবে না, সেটা const; যেটা বদলাবে, সেটা let।

let, const, var

আজকের নিয়ম

  • const — ডিফল্ট
  • let — বদলাবে
  • var — পুরনো, এড়াও

কেন

  • const ভুল বদল ঠেকায়
  • let স্পষ্ট উদ্দেশ্য
  • var-এর scope অদ্ভুত

নতুন কোডে const দিয়ে শুরু করো, দরকার হলে let।

চারটা মানের ধরন

string, number, boolean, null

Stringলেখা"Dhaka", "Mitu"
Numberসংখ্যা42, 3.14
Booleanসত্য/মিথ্যাtrue, false
null / undefinedকিছু নেইইচ্ছায় null, না দিলে undefined।
Template literal

লেখার মধ্যে মান বসানো

const name = "Mitu";
const age = 21;
console.log(`${name}-এর বয়স ${age}`);
outputMitu-এর বয়স 21

ব্যাকটিকের ভেতরে ${} দিয়ে variable বসাও।

নামকরণের নিয়ম

নাম হবে অর্থপূর্ণ: userName, totalPrice, isLoggedIn। স্পেস বা ড্যাশ নয়, camelCase ব্যবহার করো। এক অক্ষরের a, b শুধু ছোট লুপে।
