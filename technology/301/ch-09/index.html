অ্যাসিঙ্ক: অপেক্ষা করা

Async: waiting without freezing

API থেকে ডেটা আসতে সময় লাগে। অ্যাসিঙ্ক কোড সেই অপেক্ষায় পেজ আটকে না রেখে কাজ চালিয়ে যায়।

মূল ধারণা

কিছু কাজ সময় নেয়

নেটওয়ার্ক, ফাইল, ডেটাবেস — এগুলো সাথে সাথে উত্তর দেয় না। JavaScript এই অপেক্ষা ব্যাকগ্রাউন্ডে রাখে, পেজ জমে যায় না।

Sync বনাম Async

1
Sync

একটা শেষ হলে পরেরটা।

2
Async

অপেক্ষার কাজ শুরু করে এগিয়ে যায়।

3
Promise

ভবিষ্যতে ফল দেওয়ার প্রতিশ্রুতি।

4
await

ফল আসা পর্যন্ত অপেক্ষা, কিন্তু পেজ freeze নয়।

চারটা শব্দ

callback, promise, async/await, event loop

Callbackপরে ডাকার ফাংশনপুরনো ধরন।
Promiseভবিষ্যতের ফলpending, fulfilled, rejected।
async/awaitপড়তে সহজ অ্যাসিঙ্কawait দিয়ে অপেক্ষা।
Event loopকাজের ক্রম সামলায়একটা লুপে task চালায়।
Promise

একটা প্রতিশ্রুতি

const wait = (ms) => new Promise(resolve => setTimeout(resolve, ms));

wait(1000).then(() => {
  console.log("১ সেকেন্ড পরে");
});

then কাজ শেষ হলে চলে।

async / await

একই কাজ, পড়তে সহজ

async function run() {
  console.log("শুরু");
  await wait(1000);
  console.log("১ সেকেন্ড পরে");
}

run();

await শুধু async ফাংশনের ভেতরে ব্যবহার করা যায়।

fetch দিয়ে API

try/catch সহ

async function loadCourses() {
  try {
    const res = await fetch("https://api.example.com/courses");
    if (!res.ok) throw new Error("HTTP " + res.status);
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error("ব্যর্থ:", err.message);
  }
}

res.ok মিথ্যা হলে error; catch সেটা ধরে।

🪤

try/catch = নিরাপদ জাল

async কাজ ব্যর্থ হতে পারে — নেটওয়ার্ক নেই, সার্ভার বন্ধ, ভুল JSON। try-তে কাজ, catch-এ ব্যর্থতার বার্তা, finally-তে যা সবসময় করতে হবে।

একসাথে বনাম একটার পর একটা

Sequential

  • await a; await b;
  • দুটো সময় যোগ হয়
  • নির্ভর হলে দরকার

Parallel

  • await Promise.all([a, b])
  • সময় কম
  • স্বাধীন হলে ভালো

API দুটো আলাদা হলে একসাথে ডাকো।

Promise.all

দুই API একসাথে

const [users, posts] = await Promise.all([
  fetch("/users").then(r => r.json()),
  fetch("/posts").then(r => r.json()),
]);

দুটো অনুরোধ সমান্তরালে যায়; সব শেষ হলে ফল পাও।

API কলের চারটা অভ্যাস

CORS = ব্রাউজারের সীমান্ত

এক ডোমেইনের পেজ অন্য ডোমেইনের API ডাকলে ব্রাউজার অনুমতি চায়। সার্ভার Access-Control-Allow-Origin না দিলে ব্রাউজার আটকে দেয়।
