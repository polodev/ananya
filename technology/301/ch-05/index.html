ফাংশন = নাম দেওয়া কাজ

ইনপুট নাও, কাজ করো, ফল ফেরত দাও। একবার লিখে অনেকবার ব্যবহার।

ফাংশনের তিন ধাপ

1
Define

নাম আর কাজ লেখো।

2
Call

নাম দিয়ে ডাকো।

3
Return

ফলটা ফেরত পাও।

প্রথম ফাংশন

নাম নিয়ে অভিবাদন

function greet(name) {
  return "হ্যালো, " + name + "!";
}

console.log(greet("Mitu"));
outputহ্যালো, Mitu!

name হলো parameter, "Mitu" হলো argument।

চারটা শব্দ

parameter, argument, return, scope

Parameterফাংশনের ইনপুটের নামfunction greet(name)
Argumentডাকার সময় দেওয়া মানgreet("Mitu")
Returnফল ফেরত দেওয়াreturn total;
Scopevariable কোথায় দেখা যায়ফাংশনের ভেতরে local।
return বনাম console.log

একটা ফল দেয়, একটা দেখায়

function add(a, b) {
  return a + b;
}

const result = add(3, 4);
console.log(result); // 7
output7

return ছাড়া ফাংশনের ফল undefined।

তিন ধরনের ফাংশন

Declaration

  • function add() {}
  • আগে ডাকা যায়
  • সহজ

Arrow

  • const add = () => {}
  • ছোট, আধুনিক
  • callback-এ জনপ্রিয়

শুরুতে declaration, পরে arrow।

Arrow function

সংক্ষিপ্ত রূপ

const double = (n) => n * 2;

console.log(double(5)); // 10
output10

এক লাইনে return লিখতে হয় না।

🏠

Scope: variable কোথায় বাস করে

ফাংশনের ভেতরে বানানো variable বাইরে দেখা যায় না। বাইরের variable ভেতরে দেখা যায়। এটাই scope — দুর্ঘটনা কমায়।

Closure

ফাংশন তার জন্মের জায়গা মনে রাখে

function counter() {
  let count = 0;
  return () => ++count;
}

const next = counter();
console.log(next()); // 1
console.log(next()); // 2

ভেতরের ফাংশন count মনে রাখে — এটাই closure।

ভালো ফাংশনের চারটা লক্ষণ

পড়তে ও পরীক্ষা করতে সহজ

→
একটা কাজ, একটাই।
→
নাম বলছে কী করে।
→
ছোট — ২০ লাইনের কম।
→
ইনপুট দিলে একই ফল দেয়।
হিসাবের ফাংশন

দাম আর পরিমাণ

function total(price, qty) {
  return price * qty;
}

console.log(total(120, 3)); // 360
output360

ফাংশনকে ছোট রাখলে বারবার ব্যবহার করা যায়।
