লুপ = একই কাজ বারবার

একটা কাউন্টার বাড়ে, শর্ত সত্য থাকা পর্যন্ত কাজ চলে, শর্ত মিথ্যা হলে থামে।

for লুপের তিন অংশ

1
শুরু

let i = 1 — কোথা থেকে।

2
শর্ত

i <= 5 — কতদিন।

3
বৃদ্ধি

i++ — প্রতি বার কত বাড়বে।

4
কাজ

console.log(i) চলে।

প্রথম লুপ

১ থেকে ৫

for (let i = 1; i <= 5; i++) {
  console.log(i);
}
output1 2 3 4 5

i++ মানে i = i + 1।

চারটা শব্দ

for, while, break, continue

forগোনা লুপকতবার চলবে জানা।
whileশর্ত পর্যন্ত লুপকতবার জানা নেই।
breakলুপ থামাওভেতর থেকে বেরোয়।
continueএই বার বাদ দাওপরের iteration-এ যায়।
while আর break

শর্ত পর্যন্ত চলো

let i = 0;

while (true) {
  i++;
  if (i === 3) break;
  console.log(i);
}
output1 2

while (true) চলতেই থাকবে, তাই break দরকার।

♾️

Infinite loop = অনন্ত লুপ

শর্ত কখনো মিথ্যা না হলে ব্রাউজার আটকে যাবে। i++ ভুলে যাওয়া বা ভুল শর্ত — সবচেয়ে সাধারণ ভুল।

অ্যারের ওপর লুপ

প্রতিটি নাম দেখাও

const names = ["Rafi", "Mitu", "Tanvir"];

for (let i = 0; i < names.length; i++) {
  console.log(names[i]);
}

for (const name of names) {
  console.log(name);
}
outputRafi Mitu Tanvir

for...of অ্যারের মান ধরে ধরে চলে।

কোন লুপ কখন?

for

  • গোনা যায়
  • index দরকার
  • শুরু-শেষ জানা

for...of / forEach

  • অ্যারের প্রতিটি মান
  • পড়তে সহজ
  • index দরকার নেই

অ্যারের জন্য for...of, সংখ্যার জন্য for।

যোগফল বের করা

১ থেকে ১০

let sum = 0;

for (let i = 1; i <= 10; i++) {
  sum += i;
}

console.log(sum); // 55
output55

sum += i মানে sum = sum + i।

লুপের চারটা ফাঁদ

→
Off-by-one: < না <=?

শর্তের ভেতরে length বদলাচ্ছে?

ছোট প্যাটার্ন

তারার ত্রিভুজ

for (let row = 1; row <= 4; row++) {
  console.log("*".repeat(row));
}
output* ** *** ****

repeat স্ট্রিং বারবার করে।
