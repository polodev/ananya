DOM = পেজের গাছ

HTML-এর প্রতিটি ট্যাগ একটা node। JavaScript সেই node খুঁজে বদলাতে পারে — লেখা, রঙ, ক্লাস, নতুন element।

element খোঁজা

querySelector

const title = document.querySelector("h1");
title.textContent = "নতুন শিরোনাম";

const box = document.querySelector(".box");
box.classList.add("active");

querySelector CSS selector দিয়ে প্রথম element খুঁজে।

চারটা শব্দ

selector, element, event, listener

Selectorকোন element#id, .class, button
Elementপেজের একটা জিনিসবাটন, div, ছবি।
Eventকিছু ঘটনাclick, submit, input।
Listenerঘটনা ধরার ফাংশনaddEventListener
ক্লিক ধরা

বাটনে চাপ

const btn = document.querySelector("#myBtn");

btn.addEventListener("click", () => {
  console.log("চাপা হয়েছে!");
});

প্রতিবার ক্লিকে ফাংশনটা চলে।

একটা ক্লিকের যাত্রা

1

ব্রাউজার ক্লিক ঘটায়।

2
Listener

তোমার ফাংশন ডাকে।

3
State

তুমি ডেটা বদলাও।

4
DOM

লেখা/ক্লাস বদলাও।

5
Paint

স্ক্রিন আপডেট হয়।

ছোট টুডু

লেখা যোগ করা

const input = document.querySelector("#todo");
const list = document.querySelector("#list");

function addTodo() {
  const li = document.createElement("li");
  li.textContent = input.value;
  list.appendChild(li);
  input.value = "";
}

createElement নতুন node বানায়, appendChild যোগ করে।

👁️

classList দিয়ে দেখাও-লুকাও

box.classList.add("hidden") দিয়ে লুকাও, remove দিয়ে দেখাও, toggle দিয়ে বদলাও। CSS-এ .hidden { display:none } লিখো।

ফর্ম ধরো

পেজ রিলোড ঠেকাও

const form = document.querySelector("form");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log("ফর্ম পাঠানো হলো");
});

preventDefault ব্রাউজারের ডিফল্ট রিলোড থামায়।

DOM-এর চারটা অভ্যাস

কেউ ইনপুটে <script> লিখলে innerHTML দিয়ে বসালে সেটা চলতে পারে। তাই textContent ব্যবহার করো, অথবা sanitize করো।
