শর্ত = কোডের সিদ্ধান্ত

কোনো শর্ত সত্য হলে এক কাজ, মিথ্যা হলে অন্য কাজ। এটাই if / else।

if কীভাবে চলে

1
শর্ত

age >= 18 পরীক্ষা হয়।

2
সত্য

ভেতরের কোড চলে।

3
মিথ্যা

else-এ যায়।

4
শেষ

পরের লাইনে চলে।

প্রথম if / else

বয়স যাচাই

const age = 20;

if (age >= 18) {
  console.log("ভোট দিতে পারবে");
} else {
  console.log("এখনো পারবে না");
}
outputভোট দিতে পারবে

শর্ত বন্ধনীর ভেতরে, কাজ curly brace-এর ভেতরে।

চারটা শব্দ

condition, block, else if, ternary

Conditionসত্য/মিথ্যা প্রশ্নmarks >= 80
Blockকোডের দল{ ... }
else ifআরেকটা শর্তএকাধিক ধাপ।
Ternaryছোট if-elsex > 0 ? "হ্যাঁ" : "না"
একাধিক শর্ত

grade বের করা

const marks = 76;

if (marks >= 80) {
  console.log("A+");
} else if (marks >= 70) {
  console.log("A");
} else {
  console.log("আরও চেষ্টা");
}
outputA

উপরের শর্ত আগে; প্রথম সত্য হলেই থামে।

🧠

Truthy/falsy আবার

if (user) মানে user সত্য হলে। কিন্তু if (user.name)-এ user নেই বলে error হতে পারে। তাই আগে if (user && user.name) করো।

একসাথে শর্ত

&&, ||, !

const isLoggedIn = true;
const isAdmin = false;

if (isLoggedIn && isAdmin) {
  console.log("admin panel");
}

if (!isLoggedIn) {
  console.log("আগে লগইন করো");
}

&& = দুইটাই, || = যেকোনো একটা, ! = উল্টো।

switch

অনেকগুলো নির্দিষ্ট অপশন

const day = "শুক্রবার";

switch (day) {
  case "শুক্রবার":
    console.log("ছুটি!");
    break;
  default:
    console.log("কাজের দিন");
}
outputছুটি!

break না দিলে পরের case-ও চলে যায়।

ভালো শর্ত লেখার নিয়ম

স্পষ্টতা আগে

→
শর্ত ছোট আর পড়ার মতো রাখো।
→
সব edge case ভাবো: খালি, শূন্য, undefined।
→
ইনপুট যাচাই করো, ধরে নিও না।
→
গভীর nesting এড়াও — আগে return করো।
ফর্ম যাচাই

বাস্তব উদাহরণ

function validateEmail(email) {
  if (!email) return "ইমেইল দাও";
  if (!email.includes("@")) return "ঠিকানা ভুল";
  return "ঠিক আছে";
}

console.log(validateEmail("mitu@example.com"));
outputঠিক আছে

প্রথমেই খারাপ অবস্থা ফেরত দিলে কোড পরিষ্কার থাকে।
