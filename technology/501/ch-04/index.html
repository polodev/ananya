LAMP = ওয়েবের পুরনো চার স্তম্ভ

Linux + Apache + MySQL + PHP। এই চারটা দিয়ে ২০০০-এর দশকে অসংখ্য ওয়েবসাইট চলেছে। আজও অনেক চলে।

🏢

Oracle কেনায় উদ্বেগ

MySQL ছিল open source, কিন্তু মালিক বদলাল। ডেভেলপারদের ভয়: ভবিষ্যতে বন্ধ হবে কি? তাই কেউ কেউ বিকল্প খুঁজতে শুরু করে।

চারটা শব্দ

GPL, dual license, storage engine, InnoDB

GPLকোড খোলা রাখার লাইসেন্সব্যবহার, বদল, বিতরণ।
Dual licenseদুই রকম লাইসেন্সওপেন source + বাণিজ্যিক।
Storage engineডেটা কীভাবে রাখবেInnoDB, MyISAM।
InnoDBআজকের ডিফল্টtransaction আর foreign key।
🔁

InnoDB = transaction আর foreign key

পুরনো MyISAM-এ transaction ছিল না। InnoDB আসার পর MySQL ব্যাংক-ধরনের কাজেও ব্যবহারযোগ্য হয়।

MySQL-এ প্রথম ধাপ

ডেটাবেস, টেবিল, সারি

CREATE DATABASE shop;
USE shop;

CREATE TABLE products (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100),
  price DECIMAL(10,2)
);

INSERT INTO products (name, price) VALUES ('চা', 20.00);

MySQL-এ AUTO_INCREMENT, VARCHAR, DECIMAL সাধারণ।

🌍

MySQL আজ কোথায়?

অসংখ্য shared hosting, পুরনো অ্যাপ, WordPress সাইটে MySQL চলছে। নতুন প্রজেক্টে PostgreSQL বা MariaDB বেশি দেখা যায়, কিন্তু MySQL এখনও বিশাল।
