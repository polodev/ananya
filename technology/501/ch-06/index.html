তোমার জন্য

প্রোডাক্টের তথ্য দ্রুত বদলালে document DB সুবিধা দিতে পারে।

তিন ধরনের ডেটাবেস

Relational

  • টেবিল + JOIN
  • PostgreSQL, MySQL
  • হিসাব, অর্ডার

Document / embedded

  • ডকুমেন্ট / ফাইল
  • MongoDB, SQLite
  • ক্যাটালগ, মোবাইল অ্যাপ

শুরুতে PostgreSQL বা SQLite; ডকুমেন্ট দরকার হলে MongoDB।

চারটা শব্দ

ACID, JSONB, extension, transaction

ACIDনিরাপদ লেনদেনের গুণAtomic, Consistent, Isolated, Durable।
JSONBPostgreSQL-এ JSONদ্রুত খোঁজা যায়।
Extensionনতুন ক্ষমতাPostGIS, pg_trgm।
Transactionসব বা কিছু নাটাকা, অর্ডার, স্টক।
