চারটা শব্দ

JOIN, INNER JOIN, LEFT JOIN, ON

JOINদুই টেবিল জোড়াসাধারণত INNER।
INNER JOINদুই দিকেই মিললেমিল নেই এমন বাদ।
LEFT JOINবাঁ দিকের সব রাখেডান দিকে না মিললে NULL।
ONকী শর্তে জোড়াON orders.user_id = users.id
INNER JOIN

যাদের অর্ডার আছে

SELECT users.name, orders.total
FROM users
INNER JOIN orders ON orders.user_id = users.id;
outputMitu | 450 Rafi | 120

শুধু যাদের অর্ডার আছে, তারাই আসে।

LEFT JOIN

সব ইউজার, অর্ডার থাকুক বা না

SELECT users.name, orders.total
FROM users
LEFT JOIN orders ON orders.user_id = users.id;
outputMitu | 450 Rafi | 120 Nadia | NULL

অর্ডার না থাকলে total NULL।

JOIN-এর ধরন

INNER

  • দুই দিকেই মিল
  • শুধু সম্পর্কিত

LEFT / RIGHT

  • এক দিকের সব
  • অন্য দিক NULL হতে পারে

‘সব ইউজার দেখাও’ → LEFT JOIN।

JOIN + GROUP BY

প্রতি ইউজারের মোট খরচ

SELECT users.name, SUM(orders.total) AS spent
FROM users
LEFT JOIN orders ON orders.user_id = users.id
GROUP BY users.id, users.name
ORDER BY spent DESC;

প্রতি ইউজারের অর্ডার যোগ করে সাজায়।

N+1 query সমস্যা

প্রথমে ১০০ ইউজার আনলে, তারপর প্রতিটির জন্য আলাদা অর্ডার query — ১০১টা query। এক JOIN বা এক batch query-তে কাজটা করা যায়।
