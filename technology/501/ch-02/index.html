মূল ধারণা
🔎

SQL = ডেটার সাথে কথা বলার ভাষা

SELECT দিয়ে খোঁজো, INSERT দিয়ে যোগ করো, UPDATE দিয়ে বদলাও, DELETE দিয়ে মুছো।

সব দেখো

SELECT

SELECT * FROM students;
outputid | name | city 1 | Mitu | Dhaka 2 | Rafi | Sylhet

* মানে সব কলাম।

চারটা শব্দ

SELECT, WHERE, ORDER BY, LIMIT

SELECTকোন কলাম চাইSELECT name, city।
WHEREকোন শর্তেWHERE city = 'Dhaka'।
ORDER BYকীভাবে সাজাবেORDER BY name ASC।
LIMITকতটিLIMIT 10।
শর্ত ও সাজানো

WHERE + ORDER BY

SELECT name, age
FROM students
WHERE city = 'Dhaka'
ORDER BY age DESC
LIMIT 5;

ঢাকার ছাত্রদের বয়স অনুযায়ী বড় থেকে ছোট, প্রথম ৫।

যোগ, বদল, মুছা

INSERT / UPDATE / DELETE

INSERT INTO students (name, city, age)
VALUES ('Tanvir', 'Chandpur', 22);

UPDATE students
SET city = 'Sylhet'
WHERE id = 2;

DELETE FROM students
WHERE id = 3;

প্রতিটি বদলের আগে WHERE ঠিক আছে কি না দেখো।

⚠️

DELETE-এর আগে WHERE

DELETE FROM students; লিখলে সব সারি মুছে যাবে। WHERE ছাড়া DELETE বা UPDATE প্রায় কখনো নয়। আগে SELECT দিয়ে একই WHERE চালিয়ে দেখো।

হিসাব

COUNT, SUM, AVG

SELECT COUNT(*) AS total,
       AVG(age) AS avg_age,
       MAX(age) AS oldest
FROM students;

Aggregate function অনেক সারিকে এক ফল বানায়।

দলবদ্ধ হিসাব

GROUP BY

SELECT city, COUNT(*) AS students
FROM students
GROUP BY city
ORDER BY students DESC;

প্রতিটি শহরে কতজন ছাত্র, তা গুনে সাজায়।

SQL-এর চারটা অভ্যাস

ছোট নিয়ম, বড় বাঁচা

→
আগে SELECT দিয়ে যাচাই করো।
→
WHERE ছাড়া UPDATE/DELETE নয়।
→
কলামের নাম স্পষ্ট লেখো, * এড়াও।
→
টাকার হিসাবে DECIMAL, float নয়।
