AWS কেন জিতল?

প্রথমে বাজারে আসা, অসংখ্য সেবা, বিশ্বজুড়ে region, আর ডেভেলপারদের জন্য সহজ API। আজ Azure আর Google Cloud কড়া প্রতিদ্বন্দ্বী।

AWS-এর চারটা সেবা

S3, EC2, RDS, Lambda

S3ফাইল/object storageছবি, ব্যাকআপ, static site।
EC2ভার্চুয়াল সার্ভারনিজের মতো OS চালাও।
RDSmanaged databaseMySQL/PostgreSQL সহজে।
Lambdaserverless functionরিকোয়েস্টে কোড চলে।
📬

Prime = সাবস্ক্রিপশনের শক্তি

একবার ফি দিলে দ্রুত ডেলিভারি, ভিডিও, মিউজিক। এতে গ্রাহক থাকে, আর বেশি কেনে। এটা lock-in নয়, অভ্যাস।
