Network effect

যত বেশি মানুষ ব্যবহার করে, সেবাটা তত দামি হয় — বন্ধু সবাই Facebook-এ, তাই তুমিও থাকো। এটাই social network-এর moat।

🌱

Open source-ও অস্ত্র

Google Chromium/Android, Meta Llama, Microsoft GitHub — open source দিয়ে ডেভেলপার ecosystem গড়ে।
