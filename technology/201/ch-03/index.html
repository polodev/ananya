সার্ভার = ২৪ ঘণ্টা খোলা রান্নাঘর

ব্রাউজার অর্ডার পাঠায়, সার্ভার যাচাই করে, ডেটাবেস থেকে জিনিস আনে, তারপর উত্তর দেয়। ভুল হলে error response দেয়।

একটা API রিকোয়েস্ট

1
Route

/courses কোন কোড চলবে ঠিক করে।

2
Middleware

লগইন, লগ, validation চেক করে।

3
Logic

ব্যবসার নিয়ম চালায়।

4
Database

ডেটা পড়ে বা লেখে।

5
Response

JSON বা HTML ফেরত দেয়।

ব্যাকএন্ডের চারটা শব্দ

route, controller, middleware, ORM

Routeকোন URL কোন কাজGET /courses।
Controllerকাজের আসল ফাংশনডেটা এনে response বানায়।
Middlewareআগে-পরে চলা চেকauth, logging, rate limit।
ORMকোড দিয়ে ডেটাবেসটেবিলকে object-এর মতো ব্যবহার।

জনপ্রিয়

  • JavaScript / Node.js
  • PHP / Laravel
  • Python / Django

বড় সিস্টেম

  • Java / Spring
  • C# / .NET
  • Go

ভাষা যেটাই হোক, ধারণা এক: route, logic, database, response।

সবচেয়ে ছোট সার্ভার

Node.js + Express

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('হ্যালো!');
});

app.listen(3000);

app.get('/') মানে: এই ঠিকানায় GET এলে এই ফাংশন চলবে।

API-এর চারটা শব্দ

API, REST, GraphQL, JSON

APIদুই সফটওয়্যারের চুক্তিকী চাইলে কী পাবে।
RESTURL + HTTP method দিয়ে ডিজাইনGET /users, POST /users।
GraphQLএক রিকোয়েস্টে ঠিক যেটা দরকারclient নিজে ফিল্ড বাছে।
JSONডেটার সাধারণ ফরম্যাট{ "name": "Mitu" }।

লগইন ও session

1
Form

ইমেইল-পাসওয়ার্ড আসে।

2
Hash

সার্ভার পাসওয়ার্ডের হ্যাশ মিলায়।

3
Session

সার্ভার মনে রাখে, cookie দেয়।

4
Request

পরের অনুরোধে cookie আসে।

5
Allow

সার্ভার চিনে ফেলে, ঢুকতে দেয়।

Session বনাম JWT

Session

  • সার্ভারে অবস্থা থাকে
  • ব্রাউজার cookie রাখে
  • বাতিল করা সহজ

JWT

  • টোকেনেই তথ্য থাকে
  • সার্ভারে state লাগে না
  • বাতিল করা কঠিন

ছোট অ্যাপে session সহজ; distributed সিস্টেমে JWT জনপ্রিয়।

🪪

Authentication বনাম Authorization

Authentication = তুমি কে? (লগইন)। Authorization = তুমি কী করতে পারো? (admin না user)। দুটো আলাদা প্রশ্ন, দুটোই দরকার।

ব্যাকএন্ড যেসব কাজ করে

শুধু ডেটা পাঠানো নয়

→
ইনপুট যাচাই (validation)।
→
লগইন ও অনুমতি (auth)।
→
ডেটাবেস পড়া-লেখা।
→
ফাইল, ইমেইল, পেমেন্ট, লগ।
🧯

Error handling ভদ্রতার লক্ষণ

ব্যবহারকারীকে অস্পষ্ট error দিও না, কিন্তু পাসওয়ার্ড বা ডেটাবেসের ভেতরের কথা বলো না। লগে বিস্তারিত রাখো, response-এ নিরাপদ বার্তা দাও।
