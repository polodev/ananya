APIs, integrations and SaaS

আধুনিক অ্যাপ = অনেক সার্ভিসের জোড়

নিজে সব বানাতে হয় না। পেমেন্টে Stripe, ইমেইলে SendGrid, ম্যাপে Google Maps, মেসেজে Twilio — API দিয়ে জোড়া লাগাও।

API-এর চারটা শব্দ

endpoint, API key, rate limit, webhook

EndpointAPI-র একটা দরজাGET /users, POST /orders।
API keyতোমার পরিচয়পত্রগোপন রাখো, code-এ প্রকাশ করো না।
Rate limitকতবার ডাকতে পারবেসীমা ছাড়ালে 429 error।
Webhookউল্টো খবরসার্ভিস তোমাকে ঘটনা জানায়।

1

REST বনাম GraphQL

REST

  • URL + method
  • সহজ, জনপ্রিয়
  • কয়েকবার ডাকতে হতে পারে

GraphQL

  • এক endpoint
  • client ঠিক করে কী চায়
  • জটিলতা বেশি

ছোট API-তে REST, জটিল client-এ GraphQL।

fetch দিয়ে API কল

JavaScript

const res = await fetch('https://api.example.com/courses');
const data = await res.json();
console.log(data);

await মানে উত্তর আসা পর্যন্ত অপেক্ষা; তারপর JSON পড়ো।

🔔

Webhook = উল্টো API

সাধারণত তুমি সার্ভিসকে ডাকো। Webhook-এ সার্ভিস তোমাকে ডাকে — ‘পেমেন্ট সফল হয়েছে’, ‘নতুন মেসেজ এসেছে’। তাই webhook endpoint নিরাপদ রাখো।

অনুমতির চারটা শব্দ

OAuth, token, scope, sandbox

OAuthঅন্য অ্যাপে নিরাপদে লগইনGoogle/Facebook login।
Tokenসাময়িক চাবিমেয়াদ শেষ হয়।
Scopeকতটুকু অনুমতিশুধু প্রোফাইল, শুধু ইমেইল।
Sandboxপরীক্ষার জায়গাআসল টাকা ছাড়া টেস্ট।

SaaS = ভাড়া করা সফটওয়্যার

Gmail, Canva, Shopify, Notion — কিনে রাখো না, মাসে ভাড়া নাও। ডেভেলপারের জন্য SaaS মানে recurring revenue আর একই কোড সব গ্রাহককে।

Secret কোথায় রাখবে?

API key, database password, token — .env ফাইলে রাখো, Git-এ commit করো না। ভুলে commit হলে সাথে সাথে key বদলাও।
