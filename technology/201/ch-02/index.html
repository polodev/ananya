মূল ধারণা
🌐

ব্রাউজার = ভেতরে একটা ছোট অপারেটিং সিস্টেম

সে HTML পড়ে, CSS মিলিয়ে, JavaScript চালায়, ছবি এঁকে স্ক্রিনে দেখায়। প্রতিটি সাইটের জন্য আলাদা একটা ছোট অ্যাপ চালায়।

পেজ রেন্ডারের পাঁচ ধাপ

1
HTML

ট্যাগ পড়ে DOM গাছ বানায়।

2
CSS

স্টাইল পড়ে CSSOM বানায়।

3
Layout

কোন জিনিস কোথায়, কত বড় — হিসাব করে।

4
Paint

রঙ আর ছবি আঁকে।

5
Composite

লেয়ারগুলো জোড়া লাগিয়ে স্ক্রিনে দেয়।

চারটা শব্দ

DOM, CSSOM, render tree, JS engine

DOMপেজের গাছের মতো কাঠামোপ্রতিটি ট্যাগ একটা node।
CSSOMস্টাইলের নিয়মকে কোন রঙ, কত বড়।
Render treeযা সত্যিই দেখা যাবেDOM + CSSOM।
JS engineJavaScript চালানোর মেশিনV8, SpiderMonkey, JavaScriptCore।

HTML, CSS, JavaScript

HTML

  • কাঠামো
  • হেডিং, প্যারাগ্রাফ, বাটন
  • মার্কআপ ভাষা

CSS / JS

  • CSS = চেহারা
  • JS = আচরণ
  • রঙ, ক্লিক, animation

তিনটা আলাদা কাজ, কিন্তু একসাথে একটা পেজ।

📱

Responsive: এক সাইট, সব স্ক্রিন

মোবাইলে এক কলাম, ডেস্কটপে দুই কলাম। ফিক্সড পিক্সেলের বদলে percentage, flexbox, grid, media query ব্যবহার করো।

লেআউটের চারটা টুল

viewport, media query, flexbox, grid

Viewportদৃশ্যের কতটুকু জায়গামোবাইলে width=device-width।
Media queryস্ক্রিন অনুযায়ী নিয়ম@media (min-width: 700px)।
Flexboxএক লাইনে সাজানোমেনু, বাটন, কার্ড।
Gridসারি-কলামের জালড্যাশবোর্ড, গ্যালারি।
♿

Accessibility: সবার জন্য ওয়েব

ছবিতে alt লেখো, রঙের কনট্রাস্ট রাখো, কিবোর্ড দিয়েও সব কাজ করা যায়। এটা শুধু দয়া নয় — বড় দর্শক পাওয়ার উপায়।

একটা বাটনে ক্লিক

1
Event

ব্রাউজার ক্লিক ধরে।

2
Listener

JavaScript-এর ফাংশন চলে।

3
State

ডেটা বদলায়।

4
DOM update

নতুন লেখা বা ক্লাস বসে।

5
Paint

ব্রাউজার আবার আঁকে।
