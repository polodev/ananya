ইন্টারনেট = চিঠি পাঠানোর ব্যবস্থা

ঠিকানা লাগে, খাম লাগে, পথ চেনানো ডাকপিয়ন লাগে, আর একটা নিয়ম লাগে যাতে দুই পাশ একই ভাষায় কথা বলে। ইন্টারনেটেও ঠিক তেমন চারটা জিনিস আছে।

একটা রিকোয়েস্টের পাঁচ ধাপ

1
Browser

তুমি ঠিকানা লেখো, ব্রাউজার রিকোয়েস্ট বানায়।

2
DNS

ডোমেইন নামকে IP ঠিকানায় বদলায়।

3
TCP

সার্ভারের সাথে সংযোগ স্থাপন করে।

4
HTTP

GET /page চেয়ে পাঠায়।

5
Response

সার্ভার HTML আর status code ফেরত দেয়।

ঠিকানার চারটা শব্দ

IP, IPv4, IPv6, port

IP addressডিভাইসের ঠিকানা142.250.190.78।
IPv4পুরনো ঠিকানা৪ বিলিয়ন ঠিকানা, প্রায় শেষ।
IPv6নতুন ঠিকানাঅনেক বড় ঠিকানা-space।
Portএকই ডিভাইসে আলাদা দরজাHTTP 80, HTTPS 443।

বাড়ি আর ফ্ল্যাট

চেনা জিনিসবাড়ির ঠিকানা
→
টেকের নামIP + port

IP হলো বাড়ির ঠিকানা, port হলো ফ্ল্যাট নম্বর। একই সার্ভারে ওয়েবসাইট, ডেটাবেস, মেইল — আলাদা port-এ চলে।

DNS-এর চারটা অংশ

resolver, root, TLD, authoritative

Resolverতোমার ISP বা Google-এর DNSপ্রথমে এখানেই প্রশ্ন যায়।
Rootসবচেয়ে ওপরে‘.’ থেকে শুরু।
TLDডোমেইনের শেষ অংশ.com, .org, .bd।
Authoritativeডোমেইনের আসল রেকর্ডশেষ উত্তর এখান থেকে আসে।
🔎

DNS কীভাবে খোঁজে?

তুমি example.com চাইলে resolver প্রথমে root-এ যায়, তারপর .com-এ, তারপর example.com-এর nameserver-এ। উত্তর এলে কিছুক্ষণ cache-এ রাখে — তাই বারবার পুরো পথ যায় না।

TCP বনাম UDP

TCP

  • সংযোগ স্থাপন করে
  • সব প্যাকেট পৌঁছায়
  • ওয়েব, ইমেইল, ফাইল

UDP

  • সংযোগ ছাড়াই পাঠায়
  • কিছু প্যাকেট হারাতে পারে
  • ভিডিও কল, গেম, DNS

TCP নিরাপদ কিন্তু ধীর; UDP দ্রুত কিন্তু নির্ভরযোগ্যতা কম।

HTTP-র চারটা শব্দ

request, response, header, status

Requestব্রাউজারের চাওয়াGET, POST, PUT, DELETE।
Responseসার্ভারের উত্তরHTML, JSON, ছবি।
Headerঅতিরিক্ত তথ্যcontent-type, cookie।
Status codeউত্তরের ধরন200, 301, 404, 500।
একটা HTTP কথা

ব্রাউজার যা পাঠায়, সার্ভার যা ফেরত দেয়

GET /courses HTTP/1.1
Host: example.com
Accept: text/html

HTTP/1.1 200 OK
Content-Type: text/html

প্রথম অংশ request, নিচের অংশ response।

🔢

Status code মনে রাখো

200 ঠিক আছে। 301 স্থায়ীভাবে অন্য ঠিকানায়। 404 পাওয়া যায়নি। 401 লগইন দরকার। 500 সার্ভারে সমস্যা।

🔒

HTTPS = HTTP + TLS

TLS হ্যান্ডশেকে দুই পাশ একটা গোপন চাবি ঠিক করে, তারপর সব ডেটা এনক্রিপ্ট হয়। সার্টিফিকেট প্রমাণ দেয় সার্ভারটা আসল।

মনে রাখো

✓
IP ঠিকানা, port দরজা।
✓
DNS নামকে IP-তে বদলায়।
✓
TCP পৌঁছানো নিশ্চিত করে, UDP দ্রুত।
✓
HTTP request-response, status code অর্থ বলে।
