ক্লাউড = একজন অন্যের data center, তোমার কাজে

তুমি হার্ডওয়্যার কিনো না। virtualization দিয়ে একই সার্ভারে অনেক আলাদা মেশিন চালানো হয়, প্রতিটা তোমার নিজের মতো।

ক্লাউডের চারটা শব্দ

virtualization, VM, container, orchestration

Virtualizationএকটা সার্ভারকে অনেক অংশে ভাগপ্রতিটা অংশ আলাদা মেশিনের মতো।
VMপুরো ভার্চুয়াল কম্পিউটারনিজের OS, নিজের ডিস্ক।
Containerহালকা প্যাকেজঅ্যাপ আর দরকারি জিনিস একসাথে।
Orchestrationঅনেক container চালানোKubernetes এটা করে।

বাড়ি আর রুম

চেনা জিনিসআলাদা বাড়ি
→
টেকের নামVM

VM = পুরো বাড়ি, নিজের রান্নাঘর আর বাথরুম। Container = একই বাড়ির আলাদা রুম, রান্নাঘর ভাগ করা। তাই container হালকা আর দ্রুত।

Docker image থেকে container

1
Dockerfile

অ্যাপ কীভাবে চলবে লিখো।

2
Build

image বানাও।

3
Registry

image জমা রাখো।

4
Run

যেকোনো সার্ভারে container চালাও।

VM বনাম Container

VM

  • পুরো OS
  • ভারী, ধীরে চালু
  • শক্তিশালী isolation

Container

  • OS শেয়ার করে
  • হালকা, দ্রুত
  • একই অ্যাপ সব জায়গায়

শুরুতে container, আলাদা OS দরকার হলে VM।

স্কেল করার চারটা শব্দ

load balancer, autoscaling, region, uptime

Load balancerট্রাফিক ভাগ করেএক সার্ভারে ভিড় হলে অন্যটায় পাঠায়।
Autoscalingপ্রয়োজনে সার্ভার বাড়ে-কমেরাত ৩টায় খরচ কম।
Regionকোন দেশে data centerকাছের region = কম latency।
Uptimeসেবা চালু থাকার মাপ99.9% মানে মাসে কিছু মিনিট বন্ধ।
⚡

Serverless = সার্ভার নেই না, তুমি দেখো না

তুমি শুধু ফাংশন লেখো; কেউ একটা রিকোয়েস্ট এলে ক্লাউড সেটা চালায়। ব্যবহার না হলে খরচ শূন্য, কিন্তু ঠান্ডা শুরু হতে সময় লাগতে পারে।

কাছের region
১০–১০০ms

latency-এর পার্থক্য

ঢাকা থেকে সিঙ্গাপুরের সার্ভারে যেতে কম সময় লাগে, আমেরিকার সার্ভারে বেশি। ব্যবহারকারীর কাছে region বাছাই করা গুরুত্বপূর্ণ।

CDN দিয়ে দূরত্ব কমানো যায়।

কখন ক্লাউড, কখন নিজের সার্ভার?

দাম আর নিয়ন্ত্রণের হিসাব

→
ক্লাউড: দ্রুত শুরু, কম লোক, প্রয়োজনে বাড়ে।
→
নিজের সার্ভার: দীর্ঘমেয়াদে সস্তা, পুরো নিয়ন্ত্রণ।
→
Compliance: ডেটা কোথায় থাকবে, সেটা জানা দরকার।
→
Lock-in: এক কোম্পানির বিশেষ সেবায় আটকে যাওয়া এড়াও।
💳

ক্লাউড বিল = ভাড়ার বিল

CPU, GPU, storage, bandwidth, database — প্রতিটা আলাদা। সার্ভার বন্ধ করতে ভুলে গেলে মাস শেষে বড় বিল আসে। Budget alert আর resource limit রাখো।
