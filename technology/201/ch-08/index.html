মূল ধারণা
🛡️

Security = অভ্যাস, শুধু টুল নয়

আপডেট, শক্ত পাসওয়ার্ড, কম অনুমতি, ব্যাকআপ — এই অভ্যাসগুলোই সবচেয়ে বেশি কাজে দেয়।

চারটা মূল শব্দ

authentication, authorization, encryption, hashing

Authenticationতুমি কেলগইন, OTP, passkey।
Authorizationতুমি কী করতে পারোadmin, user, guest।
Encryptionপড়ার অযোগ্য করাHTTPS, ডেটা at rest।
Hashingএকমুখী রূপান্তরপাসওয়ার্ড সংরক্ষণে।
🔐

পাসওয়ার্ড হ্যাশ, plain text নয়

ডেটাবেসে পাসওয়ার্ড কখনো সরাসরি রাখো না। bcrypt বা Argon2 দিয়ে হ্যাশ করো। হ্যাশ থেকে মূল পাসওয়ার্ড ফেরানো যায় না।

আক্রমণের চারটা নাম

phishing, 2FA, password manager, session hijack

Phishingভুয়া লিংক/ইমেইল‘তোমার অ্যাকাউন্ট বন্ধ হয়ে যাবে’ — ভয় দেখায়।
2FAদুই ধাপের যাচাইপাসওয়ার্ড + OTP/authenticator।
Password managerপ্রতিটা সাইটের আলাদা পাসওয়ার্ডমনে রাখতে হয় না।
Session hijackcookie চুরিHTTPS আর HttpOnly cookie বাঁচায়।

তিনটা ক্লাসিক আক্রমণ

Injection

  • SQL/কমান্ডে কোড ঢোকানো
  • ইনপুট যাচাই + parameterized query

XSS / CSRF

  • পেজে স্ক্রিপ্ট ঢোকানো / অনুরোধ জাল করা
  • escape, CSP, CSRF token

নিয়ম এক: ব্যবহারকারীর ইনপুটকে কখনো বিশ্বাস করো না।

SQL injection এড়াও

ভুল বনাম নিরাপদ

// ভুল: স্ট্রিং জোড়া লাগানো
const q = "SELECT * FROM users WHERE name='" + name + "'";

// নিরাপদ: parameterized query
const q = 'SELECT * FROM users WHERE name = ?';
db.query(q, [name]);

? জায়গায় মান আলাদা করে পাঠানো হয়, তাই কোড ঢুকতে পারে না।

🔒

HTTPS সব সমস্যার সমাধান নয়

HTTPS পথে ডেটা এনক্রিপ্ট করে, কিন্তু ভুয়া সাইটও HTTPS নিতে পারে। তাই ঠিকানা, সার্টিফিকেট, আর সাইট কে চালায় — সব দেখো।

সাইট নিরাপদ রাখার পাঁচ কাজ

মৌলিক অভ্যাস

→
সব সফটওয়্যার আপডেট রাখো।
→
প্রয়োজন অনুযায়ী সবচেয়ে কম অনুমতি দাও।
→
প্রতিদিন ব্যাকআপ, মাঝে মাঝে restore টেস্ট।
→
লগ রাখো, সন্দেহজনক কিছু দেখো।
→
লগইনে rate limit আর 2FA দাও।
🧹

প্রাইভেসি = কম ডেটা রাখা

যে ডেটা দরকার নেই, সেটা সংগ্রহ করো না। রাখলে কোথায় রাখছ, কে দেখতে পারে, কতদিন রাখছ — লিখে রাখো।

📵

বাংলাদেশে সাধারণ স্ক্যাম

ভুয়া bKash/Nagad কল, OTP চাওয়া, ‘চাকরি পাবে’ লিংক, ফেসবুক হ্যাক। কেউ ফোনে OTP চাইলে কখনো দিও না — আসল কোম্পানিও চায় না।

🚨

কিছু হলে কী করবে?

পাসওয়ার্ড বদলাও, সব session বাতিল করো, 2FA চালু করো, ব্যাকআপ থেকে ফেরাও, ব্যবহারকারীদের জানাও। লুকিয়ে রাখলে ক্ষতি বাড়ে।
