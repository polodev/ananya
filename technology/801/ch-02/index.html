🔗

Unix দর্শন: ছোট টুল, একসাথে জোড়া

একটা টুল একটা কাজ ভালো করবে। তারপর pipe দিয়ে আরেকটার সাথে জোড়া লাগাও। এই ধারণা আজকের microservice আর command line-এ বেঁচে আছে।

🐧

Linux কেন জিতল?

কোড খোলা, যে কেউ বদলাতে পারে, কোনো কোম্পানির একচেটিয়া নয়। আজ Android-এর ভেতরে Linux, AWS-এর সার্ভারে Linux, সুপারকম্পিউটারে Linux।

🌿

Git = Linux-এর উপহার

Linus ২০০৫ সালে Linux-এর জন্য Git বানান। আজ প্রায় সব সফটওয়্যার দল Git ব্যবহার করে — কোডের ইতিহাস রাখার সবচেয়ে জনপ্রিয় উপায়।
