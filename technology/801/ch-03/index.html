সহজতা

  • Python — পড়তে সহজ
  • JavaScript — ব্রাউজারে চলে

  • C# — enterprise

ভাষা ‘ভালো-খারাপ’ নয়, কাজের সাথে মিল।

🐍

Python-এর ‘ধারণা’

Python-এ syntax পরিষ্কার, indentation মানতে হয়, library বিশাল। তাই নতুনদের শেখানো আর data/AI-তে জনপ্রিয়।

🟨

JavaScript-এর অদ্ভুত জন্ম

Netscape-এ ১০ দিনে বানানো হয়, নামেও ‘Java’ আছে কিন্তু Java-র সাথে সম্পর্ক নেই। আজ browser, server, mobile — সবখানে।
