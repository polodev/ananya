ব্যাকরণ

বাসা নিয়ে বলা: es gibt, বিশেষণ আর kein / keine

es gibt মানে ‘আছে’। বাসায় কী কী জিনিস আছে, সেটা বলতে এটা ব্যবহার করো।
ist এর পরে বিশেষণ একই রকম থাকে। যেমন: ist groß, ist hell, ist neu।
kein / keine মানে ‘নেই’। কোনো জিনিস নেই বোঝাতে এটা বলো।
es gibt-এর পরে শব্দ বদলায়: der → einen / keinen (keinen Stuhl), das → ein / kein (kein Bett), die → eine / keine (keine Lampe)।

Es gibt ein Bett.

এস গিপ্ট আইন বেট।

রুমে একটা বিছানা আছে।

Das Zimmer ist groß.

ডাস ৎসিমা ইস্ট গ্রোস।

রুমটা বড়।

Es gibt keine Lampe.

এস গিপ্ট কাইনে লামপে।

কোনো বাতি নেই।

Es gibt keinen Schrank.

এস গিপ্ট কাইনেন শ্রাংক।

কোনো আলমারি নেই।
