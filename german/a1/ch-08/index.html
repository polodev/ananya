✏️ ব্যাকরণ

অ্যাকুজাটিভ: einen / eine / ein আর দাম জিজ্ঞেস করা

  • ছেলে-শব্দ der, যেমন Fisch, কিনলে বা নিলে einen হয়। যেমন: einen Fisch।
  • মেয়ে-শব্দ die আর নিরপেক্ষ-শব্দ das বদলায় না। যেমন: eine Banane, ein Brot।
  • দাম জানতে বলো: Wie viel kostet ...? মানে ‘এটার দাম কত?’
  • একটা জিনিসের জন্য kostet বলো। যেমন: Das kostet zwei Euro।

🧠 নিজে চেষ্টা করো: Ich nehme ___ Apfel.
ein / einen / eine / einem
